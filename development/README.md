# Development

This subtree mirrors ORION's development-packet structure but is **blocked from implementation before the V1 freeze gate**.

Pre-freeze packets may specify:

- intended scientific object;
- parent/donor reductions;
- frozen discriminator;
- schemas and APIs as non-executable contracts;
- known-answer and hostile cases;
- protected evaluation and authority bindings;
- honest negative terminals.

After V1 freeze, each implementation packet must bind the exact V1 handoff identity and remain isolated from protected evaluators.
