The registered exhaustive profile universes are n=2 and n=3. Requesting n=4 returns
CANNOT_CHECK with exit 2, not a pass. Explicit checks are not disabled by Python -O.
All arithmetic witnesses use fractions; the reference is not a sparse production solver.

## Main scientific corrections

Marginal coverage is not per-instance truth; selected/adaptive actions require appropriate
risk guarantees. A support-local nogood semantics is not conjunction-homomorphic on an
inconsistent active environment. Revocation is not automatically structural rollback.
Liveness-only summaries miss content changes. Ambiguity need not block query consensus.
Positive bounded real costs do not prove termination; immutable snapshots do not prove
serializability. Unconditional version-space information gains are not always subadditive.
