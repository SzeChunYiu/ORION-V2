## OCM absorption contract (not yet executed)

Each imported fragment must bind: V2 commit + theorem ID + normalized statement + all
assumptions; OCM commit + adapter + implementation/model/configuration identities;
query/scope/epoch + observation/selection law; proof/checker/calibration identities;
complete read dependencies; actual parity input and expected result; negative mutation,
no-alarm control and CANNOT_CHECK case; measured resources; explicit non-consequences.

Minimum blockers before runtime adoption:

1. Statistical candidates retain UNKNOWN exact warrant unless exact evidence exists.
   A risk certificate applies only to its loss, population, selector, horizon and version.
2. Bind implementation, weights/model, prompt, decoding, checker, calibration, selector,
   assumptions, scope, epoch, normalization and resource policy. Hash equality alone is
   not an assumption verifier. Missing binding -> REVALIDATE.
3. Record exact/probabilistic/trace/static certificates as different types. Repeated
   invocation risk is not deduplicated merely because evidence ids repeat.
4. Reopening includes content, scope, spec, risk and operator/checker changes. Use old/new
   dependency unions for structural edits; no stale-cache return through an alternate API.
5. Rollback restores structural normalization and context using a transaction-safe undo.
6. Apply nogood filtering after composition, and name support-local versus consistent-
   environment semantics. Preserve the original counterexample.
7. Full runtime persistence, serialization, concurrency, crash recovery, language semantics
   and protected parent comparisons remain OCM acceptance work, not discharged here.

## Research frontier following this package

Priority A: turn F16 into a matched-resource study of certified local computation under
coupled revocation, comparing the strongest incremental/provenance/numerical parent.
Freeze native task families and a useful abstention/cost/loss frontier before outcomes.

Priority B: a genuinely correlated probabilistic evidence algebra with explicit source
uncertainty, selective calibration and evolving observation/selection laws. F09 solves
monotone activation, not this problem.

Priority C: efficient lifecycle-sufficient learning/compression for structured language
and procedures. Finite exhaustive supports are an oracle, not a scalable learner.

A rigorous parent-sufficient, negative or narrower result is valid. No existing adverse
result is revived by changing its historical identity. Independent proof reconstruction,
full parent saturation and machine refinement are still outstanding.
