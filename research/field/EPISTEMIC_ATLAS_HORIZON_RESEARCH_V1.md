# Epistemic Atlas / Horizon Research Synthesis V1

**Status:** source-bound donor synthesis for the 2026-08-30 local-to-global omission. This document supports framework reduction and manuscript positioning; it does not establish a new field object or empirical result.

## Question

How should Machine Epistemics reason about a possible global space of epistemic/intelligence mechanisms when every observed human, non-human, collective, evolutionary or machine system supplies only local evidence?

## Review lenses

1. mainstream/formal epistemology;
2. formal learning/computational epistemology;
3. social epistemology and philosophy of science;
4. identifiability/experimental design/open-world ML;
5. category/fibration/sheaf local-to-global mathematics;
6. universal-intelligence / no-free-lunch / computability limits;
7. AI epistemology and AI-for-science.

## Strong findings

### A. There is no standard field called “traditional epistemic science”

The direct parents are heterogeneous.

- **Epistemology** studies the nature, sources, limits and value of knowledge/justification.
- **Formal epistemology** uses logic, probability and other mathematical tools for epistemological questions.
- **Formal learning theory / computational epistemology** is especially close to our programme: it treats reliable convergence and scientific inquiry as formal normative problems over possible worlds.
- **Social epistemology** already extends inquiry beyond isolated human individuals to groups, testimony, networks, institutions and scientific communities.
- **Philosophy of science** studies confirmation, explanation, models, underdetermination, realism, scientific practice and method.

Therefore Machine Epistemics cannot claim that epistemology was previously only human, informal or non-executable.

### B. The defensible Machine-Epistemics residual is a system/control object

The candidate distinction is not `old epistemology -> machine epistemology`.

It is:

```text
traditional/formal/computational/social epistemology
    owns theories of knowledge, justification, reliability and epistemic systems

Machine Epistemics
    tests an executable system-level science of transitions in machine/hybrid
    scientific inquiry where mutable state includes claims plus evidence lineage,
    representations, models, tools, experiments, problems, evaluators, resources,
    generative regimes and authority boundaries.
```

This is narrower in domain and more operational in its required machine-readable state, action, receipt and prospective evaluation.

### C. Local-to-global reasoning has mature mathematical parents

Sheaf theory supplies a rigorous pattern:

```text
local data / local sections
-> compatibility on overlaps
-> possible global section
-> obstruction when no global section exists
```

Robinson's sensor-fusion work demonstrates sheaf-based integration of heterogeneous local data, consistency measures and systemic blind spots. Abramsky–Brandenburger demonstrates that local consistency can fail to admit a global section and that the failure itself can be formalized as an obstruction.

However, neither result licenses the statement that epistemic systems generally form a sheaf. The minimum defensible ORION object is an indexed/presheaf-like atlas; sheaf/cohomology semantics are domain-specific parent upgrades when their assumptions hold.

### D. Global method/intelligence rankings require a reference distribution or formal universe

No-Free-Lunch results show why context-free algorithm superiority is not available under uniform averaging over unrestricted problem classes. Legg–Hutter-style universal intelligence instead defines an explicit weighted environment class. These are useful parents for Epistemic Locality: a broad measure can be formal, but its environment class and weighting are part of the definition.

The programme should therefore distinguish:

```text
empirical atlas robustness
!=
formal universality inside an explicit universe
!=
absolute universality over all possible epistemic mechanisms
```

### E. Some ideal global epistemic procedures are computationally inaccessible

Solomonoff induction and AIXI are idealized broad constructions but are incomputable in their standard forms. This supports a further boundary:

```text
global mathematical characterization
!=
globally executable algorithm
```

The atlas/horizon programme should expose resource/computability constraints instead of treating ideal universality as an implementation target.

### F. Unknown handling in ML is a useful but weaker parent

Open-set/open-world learning distinguishes known classes from unknown inputs and, in richer forms, incrementally learns novel classes. The literature also stresses that unknown does not equal low confidence.

Machine Epistemics faces a higher-order analogue:

```text
unknown observation/class
<
unknown model family
<
unknown representation
<
unknown probe/action
<
unknown formalism
<
outside-current-atlas residual
```

The last state cannot be characterized by an invented label alone; it needs a persistent residual/obstruction witness.

### G. Identifiability and experiment design supply the correct operational notion of an “epistemic telescope”

The machine should not search directly for a thing it cannot represent. It can instead search for a new probe that splits a decision-relevant observational-equivalence class.

For candidate states `theta, theta'` and probe set `P`:

```text
theta ~_P theta'
```

when current probes cannot distinguish them under the bound evaluator.

A new probe is epistemically useful when it strictly refines the induced partition or expands justified reach. This is parent-owned by identifiability, active learning, optimal experiment design and model discrimination.

## Proposed formal objects after reduction

### 1. `EpistemicAtlas A_t`

A finite/bounded research object containing current contexts, local states, typed maps, probes, obstructions and horizon state.

### 2. `Context category C_t`

Objects are context identities; maps are typed restriction/transport/change relations.

### 3. Indexed local state family `X_c`

Each context has a local epistemic state/regime space. Reindexing is partial and witnessed.

### 4. `AtlasGluingReceipt`

Distinguishes:

- overlap compatibility;
- matching-family-only;
- global-section witnessed;
- global-section obstructed;
- cannot check.

### 5. `ObservationalPartition Pi(P_t)`

Decision-relative equivalence classes induced by current probes.

### 6. `EpistemicHorizon`

Operationally: unresolved observational equivalence plus an `OUTSIDE_CURRENT_ATLAS` sentinel. It is not an enumeration of the true complement of the atlas.

### 7. `GlobalityLevel`

```text
G0 local
G1 cover compatible
G2 transport stable
G3 atlas robust under hostile new-chart/probe challenge
G4 theorem over an explicit formal universe
```

No empirical absolute-global state.

## Key criticisms / hostile review

### Criticism 1 — “Epistemic cosmology” may be rhetorically attractive but scientifically misleading

Unlike physical cosmology, there is no established epistemic analogue of spatial homogeneity/isotropy and no evidence that possible epistemic mechanisms form one smooth homogeneous space.

**Disposition:** use cosmology only as a methodological analogy. Formal text uses `atlas`, `horizon`, `probe`, `transport`, `obstruction` and explicit assumptions.

### Criticism 2 — Sheaf language can become mathematical decoration

Pairwise compatibility does not automatically imply a global section; generic epistemic objects may not support the algebraic structure needed for cohomology.

**Disposition:** reference code makes `MATCHING_FAMILY_ONLY` distinct from `GLOBAL_SECTION_WITNESSED`. No cohomology primitive is added.

### Criticism 3 — `OUTSIDE_CURRENT_ATLAS` could become an unfalsifiable escape hatch

Any unexplained failure could be called “unknown epistemic mechanics.”

**Disposition:** require a residual/obstruction witness after ordinary errors, known model families, representation and resource explanations are dispositioned. The state has no positive mechanism content.

### Criticism 4 — Formal learning theory already owns much of the “global inquiry” ambition

Computational epistemology has long studied convergence and reliable inquiry under possible worlds.

**Disposition:** make formal learning/computational epistemology a load-bearing parent and narrow our residual to machine-mediated scientific-state control plus representational/tool/problem/evaluator/authority transitions.

### Criticism 5 — A global atlas may never converge

Fresh charts can continue to falsify current invariants.

**Disposition:** no absolute saturation. Use bounded atlas robustness and explicit horizon state.
