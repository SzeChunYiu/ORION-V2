# Epistemic Atlas and Horizon Formalism — Wave 06 V1

**Status:** bounded cross-cutting formalism hypothesis. No new kernel family, no new wave, no claim to a complete global intelligence/epistemic space, and no scientific/novelty/publication authority.

## 1. Research question

Human, non-human, collective, cultural, evolutionary and machine systems each expose only **local** adaptive/epistemic structures. The scientifically defensible question is therefore not:

> What is the complete global space of intelligence or epistemics?

A finite observer cannot establish that object empirically.

The operational question is:

> **How can a machine-mediated research system build, compare, test and expand a partial atlas of epistemic regimes while keeping transport assumptions, local-to-global failures and the boundary of current observability explicit?**

This formalism strengthens the earlier Epistemic Locality principle. It does not replace formal epistemology, formal learning/computational epistemology, social epistemology, philosophy of science, open-world learning, experimental design, category/sheaf theory or identifiability theory. Those are direct parents.

## 2. Atlas, not God's-eye space

Let

```text
E* = ideal class of possible epistemic regimes
```

serve only as a semantic placeholder. ORION does **not** assume that `E*` is enumerable, observable, computable, homogeneous, or even representable in one formal language.

At time `t`, the machine has only an **observed/constructed epistemic atlas**

```text
A_t = (C_t, X_t, T_t, P_t, O_t, H_t)
```

where:

- `C_t` — registered local contexts/charts;
- `X_t` — local epistemic state/regime objects meaningful in those contexts;
- `T_t` — typed, witnessed transport/restriction relations among contexts;
- `P_t` — registered probes/experiments/evaluators;
- `O_t` — local-to-global obstructions and unresolved residuals;
- `H_t` — current observational-horizon state.

Constitutional separation:

```text
A_t != E*
```

No finite atlas, donor study, benchmark or saturation pass licenses equality.

## 3. Local epistemic context

A local context is

```text
c = (
    environment,
    task_family,
    system_boundary,
    substrate_or_interface,
    timescale,
    resource_regime,
    criterion,
    authority_context
)
```

A capability or epistemic-validity statement is therefore local unless a stronger transport/gluing claim is separately established.

This extends the current `CapabilityContext` and Epistemic Locality semantics rather than creating a new K-family.

## 4. Base category / indexed family interpretation

Candidate mathematical interpretation:

- objects of a base category `C_t` are registered contexts;
- a morphism `f : c -> d` is a typed context transformation or transport relation;
- each context `c` has a local fiber `X_c` containing epistemic states/regimes that are meaningful in that context;
- a valid reindexing/transport operation `f*` maps a state in one context to a corresponding state in another only when its semantic and decision obligations are met.

This is naturally **fibration/presheaf-like**: local state spaces vary with context and can be reindexed along typed maps.

Important boundary:

```text
FIBRATION_OR_PRESHEAF_LIKE != VERIFIED_SHEAF
```

A domain earns sheaf language only when its cover, overlap/restriction and gluing semantics are actually defined and checked.

## 5. Covers, matching families and gluing

For a declared cover of a bounded target context

```text
{u_i : c_i -> c}
```

let `x_i` be local epistemic states on chart `c_i`.

A **matching family** requires compatibility on registered overlaps:

```text
restrict_ij(x_i) ~= restrict_ji(x_j)
```

under the declared relation/evaluator.

A **global section over the current cover** requires a separate witness `x` such that

```text
u_i*(x) = x_i
```

for all registered charts, with any approximation/loss explicitly bounded.

Therefore:

```text
PAIRWISE_COMPATIBLE
!=
GLOBAL_SECTION_WITNESSED
```

and

```text
NO_GLOBAL_SECTION
```

is a valid scientific terminal, not a failure of the framework.

This formalism borrows the local-to-global idea from sheaf theory. In domains with suitable algebraic structure, cohomological obstruction tools may be parent methods. They are **not** generic ORION primitives and must not be invoked without their mathematical prerequisites.

## 6. Approximate gluing

Exact equality is often scientifically inappropriate. A domain may instead define a registered discrepancy relation or metric

```text
d_ij(restrict_ij(x_i), restrict_ji(x_j)) <= epsilon_ij.
```

The tolerance `epsilon_ij` must be domain/decision justified. A generic numerical threshold cannot convert semantic disagreement into compatibility.

Possible parent objects include consistency radii and approximate sections from applied sheaf/data-fusion work.

## 7. Probe-induced observational equivalence

For a bounded candidate family `Theta_t` and registered probe set `P_t`, define

```text
theta ~_P theta'
```

when every bound probe/evaluator treats the two candidates as observationally indistinguishable for the registered decision.

The induced partition

```text
Pi(P_t)
```

is the current **observational partition** of the candidate family.

A decision-relevant non-identifiability exists when

```text
theta ~_P theta'
```

but the candidates require different registered scientific decisions.

This links the atlas formalism to K2 transport, K4 diagnosis, K5 frontier escalation and standard identifiability/experimental-design parents.

## 8. Epistemic horizon

The framework must not define the horizon as an enumerable complement `E* \ A_t`, because the unknown outside the atlas may not be representable.

Operationally, the **epistemic horizon** consists of:

1. unresolved decision-relevant observational equivalence classes inside the current candidate closure; and
2. an explicit `OUTSIDE_CURRENT_ATLAS` sentinel when a persistent obstruction cannot be represented by current model, representation, probe, context or formalism classes.

Unknown classes:

```text
U0 KNOWN_UNCERTAINTY
U1 OPEN_WORLD_NOVELTY
U2 MODEL_FAMILY_INSUFFICIENCY
U3 REPRESENTATION_INSUFFICIENCY
U4 PROBE_OR_ACTION_INSUFFICIENCY
U5 CONTEXT_SCALE_BOUNDARY_INSUFFICIENCY
U6 FORMALISM_OR_OPERATOR_INSUFFICIENCY
U7 OUTSIDE_CURRENT_ATLAS
```

`U7` is not a description of the missing mechanism. It is a witnessed statement that the current atlas cannot responsibly classify the residual.

## 9. Epistemic expansion

A new probe `p*` earns epistemic value when it produces a protected refinement:

```text
Pi(P_t union {p*}) strictly refines Pi(P_t)
```

for at least one decision-relevant equivalence class, or when it expands justified reach under the existing generative-regime criteria.

A new chart `c*` earns value when it:

- exposes a previously hidden failure/transport boundary;
- supplies an independently useful donor structure;
- falsifies an alleged invariant;
- creates a new valid gluing/transport relation; or
- makes a previously unresolved scientific decision identifiable.

Novelty alone does not count.

## 10. Globality ladder

Use a claim ladder rather than the word `global` without qualification:

```text
G0 LOCAL
    valid in one registered context.

G1 COVER_COMPATIBLE
    compatible across a declared finite cover; no global section implied.

G2 TRANSPORT_STABLE
    decision/relation survives a declared family of typed context transports.

G3 ATLAS_ROBUST
    survives independent hostile new-chart/new-probe challenges over the current bounded atlas.

G4 FORMAL_UNIVERSE_THEOREM
    proved for every member of an explicitly axiomatized formal universe.
```

There is intentionally no empirical `G_INFINITY_ABSOLUTE_GLOBAL` state.

A G4 theorem is universal only relative to its stated formal universe and assumptions.

## 11. No epistemic cosmological principle by default

The astronomy/cosmology analogy is useful methodologically but dangerous if taken literally.

ORION must **not** assume an epistemic analogue of spatial homogeneity or isotropy such as:

```text
all epistemic regions are statistically alike
all substrates implement the same primitive grammar
all local charts embed in one smooth global space
```

Such assumptions may be hypotheses in a specific formal universe, never constitutional defaults.

The correct lesson from cosmology is weaker: global structure can sometimes be inferred from local/limited observation only through explicit assumptions, multiple independent probes and aggressive anomaly tests.

## 12. Relation to existing epistemology

There is no single standard discipline called `traditional epistemic science`. The direct parent landscape is:

### Mainstream epistemology

Studies the nature, sources, limits and value of knowledge, justification, belief and rationality.

### Formal epistemology

Uses logic, probability and other mathematical tools to study epistemological questions.

### Formal learning / computational epistemology

Studies reliable convergence, learnability and the conditions under which inquiry can reach truth across possible worlds. This is a direct and especially strong parent for Machine Epistemics.

### Social epistemology

Studies testimony, disagreement, groups, institutions, networks and the social organization of knowledge.

### Philosophy of science / metascience

Studies confirmation, explanation, models, underdetermination, scientific practice and the empirical structure of science itself.

### AI epistemology / epistemic agency

Studies the epistemic status of AI systems, whether they can know/justify/understand, and how human epistemic responsibility changes in AI-mediated practice.

Machine Epistemics does not replace any of these.

Its candidate residual is:

> **the executable, system-level control and empirical evaluation of scientific-state transitions in machine/hybrid inquiry, where the mutable state includes not only belief but evidence lineage, representations, models, tools, experiments, problems, evaluators, resources, generative regimes and authority boundaries.**

It is narrower than epistemology in subject matter, because it targets machine-mediated inquiry/science; it is more operational in requiring machine-readable states, actions, receipts, protected comparators and prospective falsification.

## 13. ORION ownership map

No K7 is justified.

- **K0:** binds context/problem/criterion/authority identity.
- **K1:** stores plural local states and unresolved atlas alternatives.
- **K2:** owns typed context maps, overlap relations and transport/correspondence.
- **K3:** owns provenance/dependence of chart/probe evidence.
- **K4:** owns probe/action selection and responsibility diagnosis.
- **K5:** owns new-chart/new-probe/regime expansion proposals under witnessed obstruction.
- **K6:** owns globality scope, atlas saturation challenge, parity and non-authority terminals.

`epistemic_atlas.py` is a research/reference composition over these families, not a stable kernel primitive.

## 14. Strongest-parent threats

Any useful result may be fully owned by:

- formal epistemology or formal learning theory;
- statistical identifiability / partial identification;
- active learning / optimal experiment design / model discrimination;
- open-set/open-world learning;
- category/fibration/sheaf methods;
- model pluralism / scientific underdetermination;
- POMDP/metareasoning/control;
- existing K2 correspondence + K4/K5 logic without a new atlas interface.

Parent sufficiency is a valid contraction terminal.

## 15. Kill conditions

Contract the formalism if:

1. current `CapabilityContext` + K2 correspondence already reproduces every atlas decision at lower/equal complexity;
2. local compatibility is routinely mislabeled as global consistency;
3. sheaf/cohomology language is used without actual cover/restriction/gluing structure;
4. `OUTSIDE_CURRENT_ATLAS` becomes an excuse for unfalsifiable speculation;
5. probe expansion improves novelty but not decision-relevant distinguishability or justified reach;
6. G2/G3 claims collapse under fresh independent contexts;
7. a strongest mature parent already provides the same local-to-global decision with stronger guarantees.
