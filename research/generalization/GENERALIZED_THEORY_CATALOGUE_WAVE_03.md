## G03-1 — Constrained Conversion System

\[
CCS=(X,\mathcal F,\mathcal O,\Rightarrow,\mathcal M,\mathcal A,\mathcal P)
\]

- \(X\): typed objects or states;
- \(\mathcal F\): free/admitted objects;
- \(\mathcal O\): admitted transformations;
- \(\Rightarrow\): convertibility;
- \(\mathcal M\): monotones or protected non-fungible coordinates;
- \(\mathcal A\): authority ceilings;
- \(\mathcal P\): provenance and transformation receipts.

Candidate uses:

- evidence conversion;
- authority conversion;
- resource and method availability;
- scientific state transformations.

Hard rule: an admitted free transformation cannot increase a protected monotone or authority.

Parent ownership: quantum/general resource theories, accounting/internal control, type systems, formal conversion systems.

## G03-2 — Constitutional Decision and Adoption System

\[
CDAS=(P,D,I,\Gamma,R,O,A,H)
\]

- proposals \(P\);
- eligible decision makers \(D\);
- information/evidence profile \(I\);
- agenda \(\Gamma\);
- rule \(R\);
- outcome \(O\);
- adoption authority \(A\);
- appeal/reopening history \(H\).

Candidate uses:

- framework adoption;
- scientific promotion;
- portfolio selection;
- multi-agent decisions.

Hard rules:

- proposal is not adoption;
- agenda and rule identities are bound;
- strategic response is modelled where relevant;
- incomparability is not forced into one scalar;
- changing the rule after outcomes invalidates the decision.

Parent ownership: social choice, mechanism design, corporate governance, legal procedure, institutional analysis.

## G03-3 — Scale-Indexed Scientific Abstraction System

\[
SIAS=(X_\mu,X_M,\alpha,\mathcal O,\mathcal I,\epsilon,s,C)
\]

- micro and macro states;
- abstraction \(\alpha\);
- registered observables \(\mathcal O\);
- registered interventions \(\mathcal I\);
- error/loss bound \(\epsilon\);
- scale \(s\);
- context \(C\).

Candidate uses:

- representation selection;
- temporal/spatial aggregation;
- causal abstraction;
- simulation model reduction.

Hard rules:

- observables commute within tolerance;
- interventions commute when claimed;
- lost information is explicit;
- validity is scale and context indexed;
- future queries can expire the abstraction.

Parent ownership: renormalization, homogenization, MAUP, causal abstraction, lumpability/model reduction, abstract interpretation.

## G03-4 — Identifiability and Probe System

\[
IPS=(H,Q,Y,\rho,c,B)
\]

- hypotheses \(H\);
- probes \(Q\);
- outcomes \(Y\);
- response map \(\rho\);
- probe costs \(c\);
- resource bound \(B\).

Candidate uses:

- scientific diagnosis;
- search policy;
- active learning;
- experiment design;
- structural non-identifiability.

Hard rules:

- current equivalence classes are explicit;
- no separating probe yields structural non-identifiability;
- repeated samples of an unchanged non-separating probe family do not count as new identifiability;
- probe choice is cost and authority constrained.

Parent ownership: formal learning, experiment design, diagnosis, inverse problems, causal discovery, rough sets.

## G03-5 — Responsive Evaluation System

\[
RES=(W,E,\pi,\mathcal R,W',T,P,\Delta)
\]

- baseline world/distribution \(W\);
- evaluator \(E\);
- deployment policy \(\pi\);
- response mechanism \(\mathcal R\);
- post-deployment world \(W'\);
- protected target \(T\);
- proxy \(P\);
- shift/reversal \(\Delta\).

Candidate uses:

- benchmark publication effects;
- policy-sensitive science;
- strategic agents;
- institutional evaluation.

Hard rules:

- static and deployed validity are separate;
- proxy gain cannot compensate for target loss;
- response non-identifiability is explicit;
- post-deployment failures reopen the evaluation.

Parent ownership: performative prediction, Lucas critique, mechanism design, strategic classification, organizational incentives, policy evaluation.

## G03-6 — Reticulate Inheritance and Revalidation System

\[
RIRS=(N,E,\tau,S,V,R)
\]

- artifacts \(N\);
- typed multi-parent edges \(E\);
- inherited component map \(\tau\);
- alternative support families \(S\);
- validity state \(V\);
- revocation/reopening relation \(R\).

Candidate uses:

- scientific artifacts;
- framework versions;
- datasets/models/evaluators;
- multi-parent method composition.

Hard rules:

- parentage is component-level;
- cycles require explicit semantics;
- revoking one parent reopens only commitments whose surviving support families are exhausted;
- lineage never establishes correctness.

Parent ownership: W3C PROV and workflow provenance, SBOM/build graphs, stemmatology, phylogenetic networks, truth-maintenance systems.
