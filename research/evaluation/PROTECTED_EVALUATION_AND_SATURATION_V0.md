# Protected Evaluation and Bounded Saturation V0

**Status:** protocol design only.

## Evaluation layers

### E1 — coverage quality

Measure taxonomy depth, native-route completion, primary-source completion, changed-vocabulary routes, censored routes, field imbalance, new-structure rates and repo-collision corrections.

### E2 — native donor fidelity

On known-answer cases from each donor field, test preservation of decisive outputs, ordering, equivalence, allow/deny, forecast, repair or proof judgments.

### E3 — structural relation validity

Measure relation-type precision/recall, context scoping, false/missed equivalence, incorrect total ordering, counter-probe recovery, approximation/loss calibration and certificate expiration under context change.

### E4 — remote-neighbour discovery

At fixed budget, measure decisive remote-parent recall after controlling semantic/topic distance and report cost to strongest parent.

### E5 — novelty contraction

Use candidate ORION/V2 claims with hidden parents. Test discovery, faithful reconstruction, correct contraction, false contraction and strongest donor-product ties.

### E6 — V1 capability parity

Compare exact frozen V1, strongest native parent, strongest donor product and V2 candidate. No new capability can compensate for loss of validity, authority, semantic fidelity, execution integrity or honest terminals.

### E7 — solver and Jump value

Measure justified terminals, false completion, decisive probes, cost, unnecessary work, false escalation, missed escalation, preservation/reopening and frontier reach.

### E8 — fresh remote-domain transfer

Separate derivation from evaluation domains. Include business/management, engineering, medicine, politics/law, ecology/agriculture, education/psychology, language/history/arts and mathematical/physical sciences.

### E9 — independent replay and authority

Bind exact inputs, models/tools, budgets, evaluators, decisions and external adoption. Agreement among correlated systems is not independent replay.

## Hostile benchmark families

- different words / same structure;
- same words / different structure;
- local equivalence / global obstruction;
- observational tie / intervention distinction;
- safe / unsafe coarse-graining;
- redundant representation / genuine underdetermination;
- independent / correlated evidence;
- single / multiple / interaction-only responsibility;
- strategic response to evaluation;
- reticulate provenance;
- cross-generation drift;
- donor product tie;
- simple native method should beat V2 complexity.

## Primary metrics

- donor recall@budget;
- decisive-parent discovery cost;
- native-verdict preservation;
- false analogy/equivalence;
- distinguishing-probe minimality and cost;
- novelty-contraction accuracy;
- `CANNOT_CHECK` and incomparability calibration;
- justified reachability and terminal rate;
- resource-adjusted scientific value;
- unnecessary escalation/reframe/reopen;
- semantic fidelity;
- authority/provenance/integrity violations;
- fresh transfer;
- independent replay agreement.

## Saturation vector

`Sat_t = (coverage_gap, open_routes, new_coordinate_rate, new_relation_rate, new_obstruction_rate, new_transition_rate, new_failure_rate, parent_contraction_rate, benchmark_growth, unresolved_collision_rate)`.

Two complete passes count as no material change only when all declared coordinates remain below prospectively frozen thresholds and mandatory routes were actually available or explicitly censored.

## Honest terminals

- `BOUNDED_SATURATION_REACHED`
- `COVERAGE_INCOMPLETE`
- `SEARCH_ROUTE_CENSORED`
- `DONOR_RECONSTRUCTION_NOT_FIDELITY_PRESERVING`
- `STRUCTURAL_MODEL_FALSE_ANALOGY_TOO_HIGH`
- `NO_INCREMENTAL_VALUE_OVER_DONOR_PRODUCT`
- `V1_PARITY_FAILURE`
- `V2_CHANGE_HARMFUL_OR_OVERREACH`
- `CANNOT_CHECK`

Even bounded saturation does not admit V2. It only freezes the declared search state before V2 core derivation.
