# Generative-Regime / Invention Prospective Protocol V1

**Status:** prospectively specified extension after the 2026-08-30 invention/possibility-space omission finding. No outcome has been inspected for these registered tasks. This protocol does not alter any frozen P-A–P-D primary endpoint or the protected V1/V2 parity subject.

## Scientific question

Does explicitly representing and controlling a transformation of the current **generative regime** improve scientifically valid decisions beyond:

1. the current ORION-V2 concept/frame/action interfaces;
2. strongest parent-composed creativity, search, quality-diversity/open-endedness and design/problem-framing methods;
3. direct or native problem solving without an explicit regime object?

The null is parent/current-interface sufficiency.

## Hypothesis under test

A regime-level interface is useful only when the predecessor space is demonstrably insufficient and a typed transformation makes a registered capability, discriminator or scientific decision reachable while preserving required predecessor validity.

No credit is assigned for novelty alone.

## GR10 — exact synthetic regime-transformation benchmark

### Purpose

Obtain the cheapest possible exact-oracle test before historical or naturalistic work.

### Episode families

Generate small controlled tasks with hidden known answers in which the correct disposition is one of:

- `NO_TRANSFORM` — existing repertoire is sufficient;
- `REPRESENT` — current representation merges decision-distinct states;
- `ADD_OPERATOR` — target is unreachable with the frozen operator set but reachable after one admissible operator is added;
- `COMPOSE` — no new primitive is needed; composition of existing operators suffices;
- `CONSTRAINT_CHANGE` — an inherited constraint is unnecessary or blocks the valid solution;
- `TOOL_CONSTRUCT` — a new observation/intervention affordance is required for identifiability;
- `PROBLEM_POSE` — the original task is ill-posed or misses the discriminating question;
- `TRAVERSAL_CHANGE` — the space is sufficient but the current search policy is systematically deceptive;
- `REJECT_TRANSFORM` — a novel-looking transformation destroys protected predecessor cases.

### Exact oracle

For finite synthetic worlds, exhaustively enumerate the predecessor and successor reachable sets where feasible:

```text
Reach_D(Gamma) = registered reachable decisions/capabilities
```

This supplies exact labels for predecessor insufficiency, newly reachable states and protected regressions.

### Arms

- `SIMPLE_NATIVE` — solve inside the supplied regime;
- `CURRENT_F0` — strongest applicable existing parent composition without the new regime interface;
- `CURRENT_F2` — current ORION control semantics without explicit `GenerativeRegime` state;
- `PARENT_TRANSFORM` — strongest prospectively bound creativity/open-ended/search-space transformation parent;
- `F2_PLUS_REGIME_INTERFACE` — same solver/resources plus the explicit regime request/receipt interface.

If a parent arm cannot be implemented faithfully it is `CANNOT_CHECK`, not replaced by a weak strawman.

### Primary outcomes

Report a vector, not a weighted score:

```text
(transform_decision_correctness,
 false_invention_rate,
 exact_reach_gain,
 predecessor_retention,
 discriminator_access_gain,
 resource_cost)
```

Critical predecessor regression and false invention are non-compensatory.

### Kill condition

If `CURRENT_F0`, `CURRENT_F2` or the strongest parent transform arm matches `F2_PLUS_REGIME_INTERFACE` on transform decisions and protected reach at lower/equal cost, the explicit interface contracts.

## GR20 — time-sliced historical invention reconstruction

### Status

Exploratory/descriptive unless independent domain adjudication and source cutoff custody are achieved. It cannot by itself establish a causal law of invention.

### Minimal cohort

Start with **12 matched pairs** rather than a large historical atlas:

- science;
- mathematics/formal reasoning;
- engineering/tool invention;
- sport/movement;
- music/performance/composition;
- art/design/craft.

For each domain, include at least one later-successful transformation and one matched failed, ignored, near-miss or superseded transformation.

### Solver-visible cutoff

Freeze only information available at or before a predeclared epoch. Post-event terminology, later fame, later performance records and retrospective explanations remain evaluator-only.

### Task

Given the predecessor regime and observed constraints/anomalies, propose one or more bounded changes to representation, operator repertoire, constraints, tool/affordance, problem framing, traversal or coordination.

The solver is **not** scored by text similarity to the famous historical invention.

### Evaluation

Independent native/domain evaluators score:

- whether predecessor insufficiency was identified;
- whether the proposal is genuinely executable/expressible in the historical context;
- whether it creates a plausible new functional discriminator or capability;
- whether protected predecessor competence is preserved or explicitly traded off;
- whether the system simply leaked the famous answer;
- whether a simpler parent/current-interface proposal is sufficient.

Historical adoption/impact is recorded separately from functional/scientific validity.

### Kill condition

If performance collapses after source-cutoff, fame and surface-vocabulary controls, historical invention is retained only as qualitative donor material.

## GR30 — scientific transfer / naturalistic regime change

**Do not execute by default.** GR30 opens only if GR10 shows a protected residual and GR20 does not reveal that the residual is purely synthetic/surface-driven.

Use a small held-out scientific cohort in which an independent evaluator prospectively certifies predecessor insufficiency. Candidate cases may involve:

- a missing experimental discriminator requiring a tool/measurement change;
- a representation collision requiring a new variable/state split;
- a solver repertoire missing a compositional operator;
- an ill-posed research question requiring a bounded problem-genesis proposal.

GR30 is the only stage that could support adding regime transformation as a result-bearing P-C mechanism. Until then it remains a framework/interface hypothesis and flagship discussion item.

## Paper boundaries

### FLAGSHIP

May discuss `GenerativeRegime` and invention as a **candidate transition class / field-boundary hypothesis** immediately, with explicit parent-sufficiency and falsification language.

### P-A

May treat historical invention episodes as a new donor/source family and discuss transfer of transformation structure. Do **not** alter E80 endpoints or claim that the new donor family has been empirically validated.

### P-C

May clarify that method/instrument/problem changes can be regime-transform proposals and that false invention is over-escalation. Do **not** alter the frozen primary outcomes or comparator regimes. A result-bearing new mechanism requires GR30 under a new prospective identity.

### P-B / P-D

No edit required for this omission. Their current scientific objects are already sufficient unless later GR10/GR30 evidence creates a decision-changing relation/dependence requirement.
