# Epistemic Atlas / Horizon Prospective Verification Protocol V1

**Status:** prospective bounded verification. This protocol does not alter frozen P-A–P-D primary endpoints, create a new wave, create K7, or claim a complete global epistemic space.

## Scientific question

Does an explicit local-to-global atlas/horizon interface improve scientifically valid decisions beyond current ORION K0–K6 composition and strongest mature parents?

Strongest null:

```text
current K2/K4/K5 + formal-learning / identifiability / experiment-design parents
are sufficient; explicit atlas/horizon state adds no protected value.
```

## AH10 — exact reference semantics

Immediate low-cost verification using the research-only `orion_v2.epistemic_atlas` module.

Required cases:

1. two locally compatible charts, no global witness -> `MATCHING_FAMILY_ONLY`;
2. one incompatible overlap -> `GLOBAL_SECTION_OBSTRUCTED`;
3. compatible overlaps plus separate global witness -> `GLOBAL_SECTION_WITNESSED`;
4. unresolved overlap -> `CANNOT_CHECK`;
5. a new probe strictly splits a decision-relevant observational equivalence class;
6. a decorative/redundant probe produces no distinguishability gain;
7. G3 atlas robustness requires hostile fresh-chart/probe challenge;
8. G4 universality requires an explicit formal universe and theorem witness;
9. no empirical absolute-global claim state exists.

AH10 establishes only code/formal consistency.

## AH20 — exact probe and local-to-global benchmark

### Purpose

Test whether explicit atlas/horizon state changes a correct decision beyond current interfaces and strongest parents.

### Reuse-first rule

Reuse current EL10, GR10 and MX20 finite worlds when their identities and outcome custody permit it. Do not create an independent large benchmark merely for terminology.

### Episode families

- `LOCAL_ONLY` — one context is sufficient; atlas machinery should remain inactive.
- `COVER_COMPATIBLE_NO_GLOBAL_WITNESS` — local results agree on overlaps but no global claim is licensed.
- `GLOBAL_SECTION_WITNESSED` — an independent global construction/witness exists.
- `GLUING_OBSTRUCTION` — local claims cannot be jointly satisfied.
- `PROBE_REFINEMENT_REQUIRED` — current probes merge decision-distinct candidates; one new admissible probe splits them.
- `PROBE_REDUNDANT` — proposed new probe adds no distinguishability.
- `CONTEXT_TRANSPORT_VALID` — a decision transports across declared contexts.
- `CONTEXT_TRANSPORT_INVALID` — a fresh context breaks the alleged invariant.
- `OUTSIDE_ATLAS_SENTINEL` — a persistent residual remains after registered lower explanations are dispositioned; no invented positive mechanism is allowed.

### Arms

- `SIMPLE_NATIVE`;
- `CURRENT_F0` strongest parent federation;
- `CURRENT_F2` current ORION K0–K6 composition;
- `PARENT_LOCAL_GLOBAL` strongest faithfully implemented identifiability / experiment-design / sheaf-or-other local-to-global parent applicable to the episode;
- `F2_PLUS_ATLAS_HORIZON` same solver/resources plus explicit atlas/horizon request/receipt interface.

A missing faithful parent is `CANNOT_CHECK`, never replaced by a weak strawman.

### Primary outcomes

Report a vector:

```text
(local_scope_correctness,
 false_globalization_rate,
 gluing_disposition_correctness,
 transport_correctness,
 probe_selection_correctness,
 decision_relevant_partition_refinement,
 false_outside_atlas_rate,
 resource_cost)
```

False global-section claims and false `OUTSIDE_CURRENT_ATLAS` calls are non-compensatory.

### Kill condition

Contract the explicit interface when CURRENT_F2 or the strongest parent makes the same local/global, transport and probe decisions at equal/lower cost.

## AH30 — naturalistic cross-chart transfer

**Gated; do not open by default.**

Open only if AH20 shows a protected residual that cannot be reduced to existing K2/locality/experiment-design parents.

Candidate source families may include:

- human versus non-human cognition;
- individual versus collective inference;
- different scientific scales/measurement regimes;
- machine-native versus human-mimetic scientific strategies;
- independent scientific representations with nontrivial overlap/translation.

The target is not to prove one global intelligence space. The target is to test whether an atlas/transport/gluing representation makes a prospectively registered scientific decision better.
