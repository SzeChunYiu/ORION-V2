# ME-X6 — Collective Epistemics as a Noisy Measurement Problem: Exact Known-Answer Study (Registered Design V1)

**Class:** exact-oracle known-answer study — **zero model calls, fully
deterministic, CPU-seconds.** It asks whether a *typed* latent reading of
scientific-artifact channels recovers later validated capability where an
*untyped* aggregate of the same channels cannot. **Parent sufficiency is a
successful terminal** and is the protocol's own contraction rule (§1.3).

**Protocols served** — both ME-X6 protocol documents, following the ME-X3
precedent for a duplicated protocol rather than declaring either canonical:

- `MACHINE_EPISTEMICS_ME_X6_COLLECTIVE_EPISTEMICS_PROTOCOL_V1.md` §1–4, §6–8, §14–15;
- `ME_X6_COLLECTIVE_EPISTEMICS_PROTOCOL_V1.md` §2, §6–7, §11–12, **including
  X6-I7**, which has no counterpart in the long file's I1–I10 and would be
  orphaned by choosing one document;
- `MACHINE_EPISTEMICS_DECISIVE_STUDIES_PROTOCOL_V1.md` §0–§2, §8, §11.

**Status:** frozen design + development split. **No protected outcome has been
generated or inspected.** The protected stage refuses (§8).

Companion: `ME_X6_COLLECTIVE_EPISTEMICS_EXACT_STUDY_DESIGN_V1.json`
(schema `orion.v2.me-x6.exact-study-design.v1`) carries every constant below.

## 1. Question, comparator, expectation

**Q.** Given the observable channels of a field over a fit window, can a typed
latent state recover the direction of *later validated capability* where an
information-matched untyped aggregate of the same channels cannot?

### 1.1 The scope contraction, declared

Both protocols require temporal predictive validation — a rolling historical
cutoff over a real corpus (long §9 H1/H2; `TEMPORAL_HOLDOUT_REQUIRED = TRUE`).
**This design contracts that to synthetic time**: a planted latent trajectory
with a fit window and a holdout window. Both protocols license constructed cases
(long §7, short §12), but this **is** a contraction and is named as one here and
in the receipt.

The real-corpus route was not taken because it carries the hazard recorded as
item 11 of `SILENT_FAILURE_MODES_ADMISSION_ASSESSMENT_V1.md` — dateless
current-state fields leaking the future into a retrospective split, `cited_by_count`
truncated at fetch date and `is_retracted` a dateless boolean — for which no
build exists. **No claim is made about any real field, corpus, database or
period.**

### 1.2 Where the information-matching rule lands

The protocol's literal B4 (output, citation, semantic, network, team, field
size) does **not** hold the validation channels; M adds them (§6). Comparing
only against that would give M more information than its comparator, which the
master protocol forbids. So two comparators are registered:

- `B4_SCIENCE_OF_SCIENCE_LITERAL` — the protocol's literal covariate set. It is
  the ladder's fourth rung, **not** the comparator G1 tests against.
- `B4X_FITTED_UNTYPED` — the **information-matched comparator**. It receives
  *every* channel M receives and **fits one sign per channel** on the public
  development split; those signs are frozen into the design JSON before any
  protected instance exists. An equal-weight sum would be a strawman: a real
  science-of-science modeller given the validation channels would fit the
  combination. This parent is allowed to discover the very sign structure M
  declares a priori.

M is never given anything the comparator lacks. **The only difference between
them is typing.**

### 1.3 Pre-registered expectation, and what is *not* a finding

**M is exact by construction on this generator.** Its typed score reads exactly
the channels the generator uses to encode capability. Saying so before the run
is the point: **the M-vs-parent gap is therefore not the finding and must not be
reported as one.** Where an exact planner is optimal by construction, agreeing
with it is arithmetic, not evidence.

The decisive content is elsewhere:

1. **G3** — which typed channel is load-bearing for which invariance. Each
   capability-moving stratum is given a *distinct* carrier channel, so an
   ablation can be load-bearing at all; if every validated channel moved
   together, G3 would be a gate that could not fail.
2. **G5** — the hostile-invariance suite, each invariance its own positive test.
3. **G7** — the registered prediction **P-MEX6-1**, which can fail.
4. **G6** — whether the result holds separately at both units of analysis.

If the fitted parent ties M, the terminal is `PARENT_SUFFICIENT` /
`TYPING_NOT_SEPARATED` — the protocol's own §6 contraction ("if B4 predicts the
validation targets as well as M, X6 contracts to an interpretive framework"), a
legitimate publishable result and not a failure. The honest null is **"no
residual detectable in the registered decision problems the untyped aggregate
already solves exactly"**, never "typing adds nothing".

### 1.4 What kind of result this is

**A constructive separation, not a sampling study.** The claim is: *on this
constructed family of decision problems the typed reading is exact, no untyped
aggregate carrying one global sign per channel can be, and here is which
stratum separates them and which typed channel carries each.*

Every arm's decision is a strict integer sign comparison, so an arm's verdict is
**constant across the instances of a cell** — asserted, not assumed, by the hard
gate **G8**. There is therefore no chance mechanism for a paired significance
test to test. An exact p-value over 1 400 instances would report an effective
*n* of **28 cells** at an inflated denominator, in a study whose own taxonomy
names that failure. So **G1a, G1b, G4 and G6 are deterministic comparisons over
cells and report no p-value.**

**G0c is the one exception and keeps its exact binomial tails**: `C_RANDOM`
draws per instance and the shuffled-label null permutes across instances, so
those are genuine sampling quantities even in a deterministic design. Its tails
are computed in exact rational arithmetic — the float form overflows at the
registered protected size, and an overflowed tail compared against a threshold
would make a hard gate incapable of failing.

**Instances per cell buy structural coverage, not power:** a cell's verdict is
shown invariant under varying baselines, step magnitudes and step onsets. Every
gate reports **both denominators**, instances and cells, so a structural
replicate can never be read as an independent observation.

If constancy ever fails, the constructive framing is wrong and inferential
statistics *would* be required — so G8 is hard and a failure routes
`CANNOT_CHECK` rather than being absorbed.

## 2. The episode, and the joint verdict

One instance is a **field window**: a scale, a fit window of 8 periods, a
holdout of 4, a planted 8-coordinate latent trajectory (`R V D T G U C E`) and
16 observable channels per period. **No arm ever receives a latent coordinate or
a holdout period.**

The verdict has **two halves, decided jointly**:

| half | from | directions |
|---|---|---|
| `capability` | the planted capability coordinates `R`, `V` | RISE / FLAT / FALL |
| `activity` | the activity channels | RISE / FLAT / FALL |

Exact match requires both. Reporting them jointly *is* the measurement: a
volume-reading surface is **right about activity and wrong about capability**,
which is `PAPER_COUNT = ACTIVITY_NOT_KNOWLEDGE` turned into a number. Every arm
that holds the activity channels reads them directly — no arm is crippled on a
half it plainly has the information for. **The contest is capability.**

### 2.1 Per-instance structural variation

Three structural quantities are drawn per instance: a **per-channel baseline
level**, a **per-instance step magnitude**, and the **period at which the step
lands**, inside the second half of the fit window. The two scales draw from
different ranges.

None of them can move a direction. Each compared half has the same number of
periods, so a baseline contributes equally to both; all channels of an instance
share one step magnitude, so every relative weight in the typed score — notably
I4's retraction dominance — is preserved exactly; and the onset lies inside the
second half of the fit window, so both the arms' comparison and the oracle's see
the full step and only the *magnitude* of the difference varies.

This is required, not decorative. Without it the window was a pure function of
`(stratum, scale)`: the seed did no work, the **scale never reached the window**
so cross-scale transfer would have been a contrast that could not exist, a
1 400-instance split would have been 14 distinct windows replicated 100 times,
and every paired exact p-value would have been computed over pseudo-replicates
at an inflated denominator — in the direction of apparent strength. Caught
before the freeze merged.

### 2.2 No stochastic noise, and why

The generator plants **no additive jitter**. ME-X6's noise is *structural*: a
channel is a noisy readout of the latent state because perturbations **decouple**
it — duplicates raise volume without capability, a citation ring raises attention
without either — and those perturbations are modelled explicitly as strata.
Sampling noise on top would convert exact statements into rates and buy nothing.
Every direction is therefore a strict integer comparison and **there is no
threshold to tune anywhere in the oracle.**

### 2.3 The known-answer property, asserted per instance

The design is a known-answer study only because the holdout direction is already
carried by the fit window. `decidable_from_fit_window` asserts that **instance by
instance** rather than leaving it as prose, and G0b fails if it ever does not hold.

## 5. Gates (frozen before any protected outcome exists)

Every gate is a **positive test carrying its own `n_evaluated`**. A gate with
`n_evaluated = 0` reports `CANNOT_CHECK`, never a pass.

- **G0a `KNOWN_ANSWER` (hard)** — every cell's recomputed verdict equals its
  declared effect, and the four planted positives fire, in the selftest report.
- **G0b `ORACLE_SELF_AGREEMENT` (hard)** — the planter's declared effect equals
  the full-structure recomputation on every instance, and every instance is
  decidable from its fit window.
- **G0c `NULL_CALIBRATION` (hard)** — the degenerate controls score **zero**
  where their answer is wrong; the random control is not significantly above its
  **derived** 1/3 expectation and the shuffled-label null is not significantly
  above the **computed** majority-class rate. **This gate carries no threshold
  constant**: both reference values come from the split. `C_ALWAYS_FLAT`'s exact
  rate is printed beside the majority-class rate so a degenerate control's score
  cannot be read as skill.
- **G1a `M_AHEAD_OF_MATCHED_PARENT`** and **G1b `MATCHED_PARENT_AHEAD`** — two
  separate positive tests. A tie fires **neither**, and no terminal is the
  negation of another gate.
- **G2 `ANTI_CONSERVATISM`** — on the genuine strata M is at least as exact as
  the parent. Invariance must not be bought with abstention.
- **G3 `MECHANISM_BY_OMISSION`** — each ablation degrades **exactly** the strata
  declared to depend on it and no others, reported per ablation.
- **G4 `INFORMATION_LADDER`** — **not a monotonicity gate.** Every rung is
  fitted on its own channel set, and L2 is *still* strictly worse than L1:
  one global sign cannot **ignore** a channel that moves without capability, so
  the attention channel destroys `I5_CITATION_RING`, which L1 gets right
  precisely by not holding it. Fitting does not remove the reversal, so it is a
  property of untyped aggregation and a **finding** (P-MEX6-2), not a lane
  defect. The positive test is a **count** comparison of exact cells, top rung
  against bottom, **per scale, never pooled**.
- **G5 `HOSTILE_INVARIANCE_SUITE`** — I1–I10 and X6-I7, each its own positive
  test with its own denominator.
- **G6 `CROSS_SCALE_TRANSFER`** — separately in each scale; a result that does
  not transfer to the second unit of analysis is killed.
- **G7 `REGISTERED_PREDICTION`** — **P-MEX6-1**, below.
- **G8 `VERDICT_CONSTANCY_WITHIN_CELL` (hard)** — every arm's verdict is
  constant across the instances of a cell. This is the gate that licenses every
  deterministic comparison above. `C_RANDOM` is excluded by construction. The
  selftest carries a **planted positive that must trip it**: I4's typed sum is
  `s₁ + s₂ + s₃ − 2r`, sign-invariant only because all channels of an instance
  share one step magnitude, so a hand-built window with per-channel steps flips
  I4 from FALL to RISE and the constancy check sees it. A constancy gate never
  shown to fire would be a counter that never ran.
- **COVERAGE_LEDGER** (reported, not a gate) — every cell with its count and an
  explicit list of those exercised zero times.

### 5.1 P-MEX6-1 and P-MEX6-2, registered before the run

> The information-matched untyped parent fails **exactly** on the strata where
> the true capability direction contradicts the direction of a channel it must
> assign a single global sign to — volume and attention rising while capability
> is flat (I1, I2, I3, I5, I7, I8), or every ordinary validated channel rising
> while capability falls (I4) — **and nowhere else.**

> **P-MEX6-2.** The fitted untyped ladder is **not monotone**: adding the
> attention channel strictly reduces exactness, because one global sign per
> channel cannot **ignore** a channel that moves without capability.
> Support: `L1_ACTIVITY_ONLY -> L2_PLUS_ATTENTION`, and no other step.

Both registered from the public development split, and **both must hold** for
G7 to pass. **Falsifiers:** a failure or regression outside the declared
support, or a predicted one that does not occur. The mechanism claimed in both
is the same: one global sign per channel cannot represent *"volume counts only
when validation accompanies it"*.

| G1a ∧ ¬(G3 ∧ G4 ∧ G5 ∧ G7) | `CANNOT_CHECK` | `NONE` |

**No routing path awards an ME-X6 residual.** §1.3 declares M exact by
construction, so awarding a residual on the strength of the M-vs-parent gap
would contradict the design's own disclaimer. The all-pass terminal is a
**representational** claim carried by G3, G5, G6 and G7 — that at matched
information a single global sign per channel cannot represent *"volume counts
only when validation accompanies it"*, and that the mechanism map is established
and matches its declared prediction. It is not a residual claim and does not
share a name with one.

### 8.1 One declared exception to a house invariant

ME-X7's invariant is that **the arms never import the oracle**. `fit_signs`
does, to read capability labels. This is admissible and is declared rather than
hidden: the information-matched comparator is a **supervised** baseline, so
fitting it genuinely requires labels; it reads them only on the **public
development split**, and the resulting signs are frozen into the design JSON
before any protected instance exists.

What remains forbidden is unchanged: **no arm's decision path touches the
oracle.** `B4X_FITTED_UNTYPED` raises if it is used before its frozen signs are
loaded, and a unit test asserts that no arm reads a latent coordinate or a
holdout period.

## 9. No-rescue clause

No stratum, carrier, arm, channel, sign, gate or seed changes after the
protected results file exists. Development-only tuning surface: bug fixes to arm
glue validated by the known-answer selftest before the seed is revealed. A
protected result is never re-run under a new seed; a lane defect found mid-run
halts the lane, is receipted, and re-freezes as V2.

### 9.1 The ME-X7 lesson, built in from the start

ME-X7's protected run failed a hard gate because a generator-validity invariant
was stated as a **count** ("exactly one censored check") that was false for a
mechanism which legitimately affected two. The obvious repair silently **deleted**
the offending cell — the instances were re-drawn away and the gate went green
because the hard cases had left the split.

Here `planter_agrees` compares against a **declared per-stratum expected effect**,
never a count, and the coverage ledger names any cell drawn zero times. A
regression test asserts that every registered stratum is still drawn at protected
scale — the exact failure mode that repair would have introduced.
