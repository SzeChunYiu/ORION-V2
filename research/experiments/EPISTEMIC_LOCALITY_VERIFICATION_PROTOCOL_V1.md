# Epistemic Locality / Perspective Plurality Verification Protocol V1

**Status:** prospective verification protocol. This protocol supports the non-anthropocentric/locality framing without changing any frozen P-A–P-D primary endpoint. It does not test whether animals, evolution or machines possess one universal intelligence scalar.

## Scientific question

Does explicit binding of **environment, task family, system boundary, scale, timescale, substrate/interface and criterion** prevent scientifically relevant false universalization or incorrect method/intelligence rankings beyond the current ORION context interfaces and strongest context-conditioned parents?

The strongest null is that existing `ProblemFrame`/K2 context binding plus mature ecological-rationality, algorithm-selection and metareasoning parents are already sufficient.

## EL10 — exact synthetic locality benchmark

### Purpose

Provide the cheapest exact-oracle discriminator.

Generate finite task families in which method/system rankings are prospectively known to be:

- invariant across registered contexts;
- reversed by environment distribution;
- reversed by resource budget;
- reversed by timescale;
- reversed by system boundary/agent scale;
- incomparable/Pareto rather than totally ordered;
- invalid to compare because the criterion or evidence interface differs.

### Arms

- `GLOBAL_RANKING` — context-free scalar/ranking baseline;
- `CURRENT_F0` — strongest context-conditioned parent federation;
- `CURRENT_F2` — current ORION interfaces without explicit `PerspectiveFrame` request/receipt;
- `F2_PLUS_LOCALITY_INTERFACE` — same solver/resources with explicit locality/perspective binding.

No weak parent substitute is permitted. Missing faithful parent implementation is `CANNOT_CHECK`.

### Primary outcomes

```text
local_decision_correctness
false_universalization_rate
perspective_dependence_detection
invalid_comparison_detection
method_routing_correctness
cross_frame_transport_error
resource_cost
```

False universalization and invalid comparison are non-compensatory on critical cases.

### Kill condition

If current interfaces or strongest parents match `F2_PLUS_LOCALITY_INTERFACE` on all protected decisions at equal/lower cost, the explicit interface contracts to documentation/analysis convention.

## EL20 — diverse adaptive-system donor audit

### Purpose

Verify the conceptual boundary and prevent category error rather than claim one law of intelligence.

Build a small source-bound reconstruction set spanning at least:

- human individual cognition;
- non-human individual/embodied cognition;
- animal collective decision;
- cultural cumulative adaptation;
- evolutionary adaptation/major transitions;
- machine-native adaptive/search systems.

For each donor, reconstruct:

```text
AdaptiveSystemProfile
native mechanism
adaptation timescale
system boundary
retention/memory channel
environment/task ecology
what can and cannot be transferred
```

Require at least one negative or anti-analogy case per donor family.

### Evaluation

Independent/native or literature-grounded review checks whether the synthesis:

- preserves the distinction between cognition and evolutionary adaptation;
- avoids anthropomorphic mechanism substitution;
- identifies a genuine transferable structural distinction;
- states when transport is `CANNOT_CHECK`;
- does not infer truth or normative authority from fitness/survival.

This is primarily curation + verification, not a compute-heavy experiment.

## EL30 — gated naturalistic perspective-change study

**Not authorized by default.** Open only if EL10 shows a protected residual that is not already parent-owned.

Use a small held-out scientific cohort where an independent adjudicator certifies that a relevant conclusion or intervention changes with one of:

- system boundary;
- temporal scale;
- organizational/agent scale;
- environment/reference distribution;
- evaluator/criterion frame.

Compare ordinary context routing with explicit perspective-dependence handling. A positive result must improve a protected scientific decision, not merely produce richer metadata.

## Paper boundaries

### FLAGSHIP

May state Epistemic Locality and diverse intelligence as a **field-boundary/falsification principle** immediately, provided it is explicit that comparative/evolutionary donors motivate the hypothesis rather than prove it.

### P-C

May clarify that minimum sufficient intervention and method superiority are episode/context relative, and that `CHANGE_PERSPECTIVE`/`CHANGE_SCALE` are optional reframing actions. No current endpoint changes.

### P-A

No immediate primary-paper edit is required. Non-human adaptive systems can enter future donor reconstruction under existing native-fidelity and false-analogy controls.

### P-B / P-D

No edit required unless later EL10/EL30 results expose a new relation/dependence requirement.
