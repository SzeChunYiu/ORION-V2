# FM80 Naturalistic Transfer Decisive Protocol V1

**Freeze date:** 2026-08-30  
**Owner lane:** FM80 / issue #48  
**Purpose:** prospectively define the minimum naturalistic evidence that could support the surviving P-A and P-B standalone claims.  
**Timing:** frozen while the registered-scale FM/FG R2 campaign is still in flight; this protocol must not be altered merely because R2 is positive or negative.

## 1. Questions

### P-A question
Can source-bound structural donor discovery recover a genuinely remote scientific parent and improve a protected target-domain decision beyond strongest retrieval/analogy/parent baselines while preserving native scientific meaning?

### P-B question
When mature relation notions disagree, does an explicit typed-relation / conservative-composition / selective-reopening interface improve a protected transfer decision beyond the strongest information- and resource-matched parent composition?

A positive answer to one question does not automatically grant the other.

## 2. Minimum domain structure

The terminal study requires **three materially different domains**:

1. at least one mathematical/formal domain with a machine-checkable or expert-checkable formal witness;
2. one empirical science in which transfer/transport can be tested against measurements, interventions, or a frozen empirical benchmark;
3. a second empirical science with materially different objects, measurement semantics and strongest parent methodology.

Domain identities and exact target cases must be frozen before any study-arm outcome is read. Reusing a generated FM/FG study as one of the three domains is not sufficient.

## 3. Case eligibility

A target case is eligible only if, before arm execution:

- the scientific question and protected decision are written without the answer;
- the strongest known native parent method(s) are named;
- at least one candidate remote donor/parent is known to a private adjudication key or can be defined by a prospective discovery criterion;
- the donor is outside the target's ordinary local retrieval neighbourhood under the frozen baseline search system;
- the transfer consequence is nontrivial: correct donor/relation handling can change a registered transfer/block/reopen/retain decision;
- the case has a formal or empirical witness capable of exposing a wrong transfer;
- target-case materials visible to model arms do not contain the hidden donor key, gold relation label, or terminal disposition.

Cases failing any item are `INELIGIBLE`, not negative evidence.

## 4. Operational remoteness

A donor is `REMOTE` only if all are true under the frozen corpus/search date:

1. it is outside the target's primary field/taxonomy branch or a prospectively defined semantic neighbourhood;
2. it is absent from the top-K results of the strongest lexical+dense retrieval baseline at the matched search budget;
3. it is not named in the target prompt, metadata, citation neighbourhood or model-visible support files;
4. an independent adjudicator accepts that the donor is scientifically relevant to the registered target decision.

K, corpus snapshot and retrieval model/version must be frozen in the machine-readable companion before dispatch. A donor that is merely obscure but already surfaced by the matched baseline is not evidence for remote-donor discovery.

## 5. Arms

### A0 — strongest native parent / direct target solution
Best target-domain method available under the matched resource budget, with no cross-domain donor search.

### A1 — strongest retrieval / literature-based-discovery baseline
Sparse+dense retrieval plus the strongest allowed ordinary analogy/literature-discovery procedure, using the same searchable corpus and query/tool budget as A3.

### A2 — structure-first donor search without native-fidelity gate
Ablation that can retrieve structural analogues but does not require a typed native relation/witness before transfer. This identifies whether any gain comes merely from more cross-domain search.

### A3 — full P-A donor discovery + P-B typed transfer gate
Source-bound donor search followed by explicit relation typing, native-parent recovery/deference, uncertainty/dependence preservation where relevant, and a protected transfer/block/reopen decision.

### A4 — oracle-donor ceiling (analysis-only where ethically/operationally valid)
The hidden donor is supplied but the scientific transfer still must be solved. This is a ceiling/control, not a deployable comparator and is excluded from the primary superiority test.

All model/tool arms use the same underlying model family/version when an LLM is involved, the same maximum tool calls, searchable corpus, wall-clock budget class and output contract. Any unavoidable resource mismatch is reported and can only weaken an A3 claim.

## 6. Protected endpoints

### Primary endpoint
Per-case correctness of the **registered scientific disposition** (`TRANSFER`, `BLOCK_TRANSFER`, `REOPEN`, `RETAIN`, or case-specific equivalent), judged against the frozen formal/empirical witness and blinded adjudication.

### Co-primary safety/fidelity endpoint
`CRITICAL_NATIVE_FIDELITY_FAILURE`: a transfer that violates a named native-domain condition, relation type, measurement/causal scope, or formal witness. These failures are non-compensatory.

### Secondary endpoints

- remote-donor recovery;
- correct relation type;
- source/provenance binding;
- selective reopening accuracy;
- cost/tool calls/latency;
- abstain/unresolved calibration.

Retrieval accuracy alone cannot satisfy the paper gate.

## 7. Adjudication

For each domain:

- at least two qualified adjudicators who did not build the evaluated arm inspect blinded outputs;
- they see the frozen target contract and necessary native evidence, not arm identity;
- disagreements are recorded before any consensus meeting;
- a third independent adjudicator resolves only predeclared terminal disagreements;
- expertise, conflicts and material dependence between adjudicators are recorded;
- formal cases use machine-checkable proof/test artifacts wherever possible, with human adjudication restricted to scientific interpretation not executable truth.

Number of adjudicators is not treated as statistical independence.

## 8. Sample and analysis freeze

Minimum target: **90 eligible cases**, at least 30 per domain. If fewer than 90 eligible cases can be assembled without weakening eligibility, the study may run as a scoped pilot but cannot grant the standalone top-tier terminal below.

Primary comparison: A3 versus the strongest of A0/A1 selected by a pre-outcome rule based only on baseline identity, not A3 outcomes. Report paired differences and exact paired tests with 95% intervals; adjust across the three domain-level primary tests using Holm.

No pooled claim may hide a domain loss.

## 9. Standalone survival terminal

P-A/P-B may be promoted beyond `HOLD` only if all are satisfied:

1. A3 improves the protected decision endpoint over the frozen strongest baseline by at least **10 percentage points** in at least two of three domains;
2. the paired 95% interval for those two domain improvements excludes zero after the frozen multiplicity procedure;
3. A3 has **no increase in critical native-fidelity failures** in any domain;
4. at least one winning domain contains genuinely `REMOTE` donor cases under section 4;
5. A2 does not reproduce the A3 protected-decision gain, supporting value from the fidelity/typed-transfer gate rather than search expansion alone;
6. the effect remains after excluding cases where the donor was inadvertently visible to the baseline or prompt;
7. independent adjudication does not identify a stronger omitted parent that collapses the residual.

If only P-A-specific conditions survive, P-B does not inherit credit; if only P-B typed-transfer conditions survive, P-A does not inherit remote-donor credit.

## 10. Contraction terminals

Valid terminals include:

- `PARENT_OR_RETRIEVAL_SUFFICIENCY`;
- `REMOTE_DONOR_RECOVERY_WITHOUT_DECISION_VALUE`;
- `SEARCH_GAIN_WITHOUT_NATIVE_FIDELITY_VALUE`;
- `TYPED_TRANSFER_VALUE_WITHOUT_REMOTE_DONOR_VALUE`;
- `DOMAIN_SPECIFIC_ONLY`;
- `CRITICAL_NATIVE_FIDELITY_REGRESSION`;
- `INSUFFICIENT_ELIGIBLE_NATURALISTIC_CASES`;
- `CANNOT_CHECK_INDEPENDENT_ADJUDICATION`.

These outcomes must be publishable/recorded; none authorizes redesign of the same cases after outcome access.

## 11. Leakage and provenance

Before dispatch, hash-freeze:

- case IDs and domain membership;
- prompt-visible files;
- hidden donor/relation/disposition keys;
- corpus snapshot identifiers;
- baseline search configuration;
- model/tool versions;
- arm prompts and budgets;
- adjudication forms;
- analysis code or a complete pseudocode/specification sufficient to reproduce it.

The hidden keys must be absent from all model-visible workspaces during dispatch.

## 12. Relationship to FM/FG R2

FM/FG R2 is calibration/registered-scale generated evidence. Its result may determine prioritization and manuscript contraction, but **does not alter this naturalistic protocol's endpoints or pass rules**. A positive R2 result cannot substitute for FM80; a negative R2 result may make execution low priority but cannot justify relaxing FM80.

## Authority

This protocol grants no scientific truth, publication readiness, field status or paper survival before a valid terminal receipt. It is deliberately frozen before the FM/FG R2 outcome.
