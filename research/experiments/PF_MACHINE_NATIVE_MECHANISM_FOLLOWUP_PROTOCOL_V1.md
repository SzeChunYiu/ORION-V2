# P-F Machine-Native Mechanism Follow-up Protocol V1

**Freeze date:** 2026-08-30  
**Purpose:** define a causal mechanism test for P-F before the registered-scale FG80 R2 outcome is known.  
**Status:** conditional protocol; execution is forbidden unless the trigger below fires.

## 1. Trigger

This protocol activates only if the registered FM/FG R2 terminal shows a **predeclared, statistically supported FG80 advantage of the full machine-native/F2 arm over the simple direct control** under the R2 analysis contract.

If R2 does not establish that separation, terminal is:

`NO_R2_EFFECT_TO_EXPLAIN__P_F_STANDALONE_ROUTE_CLOSED_OR_MERGE`

No mechanism study may be launched merely because another arm comparison looks favorable post hoc.

## 2. Scientific question

If an FG80 advantage exists, is it causally attributable to a specific machine-native mechanism rather than extra compute, longer search, hidden information, richer tools, generic self-consistency, or a human-mimetic reasoning scaffold?

Difference from human procedure is not the endpoint. The endpoint is protected scientific decision value caused by a frozen substrate-relative mechanism.

## 3. Pre-dispatch mechanism manifest

Before any follow-up dispatch, create and hash-freeze a `MECHANISM_MANIFEST.json` mapping the actual current F2 implementation to components in these classes:

- representation / internal state;
- persistent memory;
- branching or non-linear search topology;
- control / scheduling policy;
- external tool interface;
- language-visible rationale/scaffold;
- compute/token/tool-call budgets.

The manifest must name the **single primary candidate mechanism** to be tested. If no specific component can be named without reading R2 per-case outcomes, the study terminates `CANNOT_IDENTIFY_PREOUTCOME_MECHANISM`.

## 4. Phase A — causal attribution on fresh held-out formal tasks

Use a fresh generated task set from the same broad FG80 family but with new seeds/templates and private oracles unavailable during arm execution. Do not reuse R2 task outcomes as the test set.

Minimum 80 eligible fresh tasks.

### Arms

- `M0_SIMPLE_DIRECT`: strongest simple direct control.
- `M1_FULL_NATIVE`: full system with the frozen mechanism present.
- `M2_MINUS_PRIMARY_MECHANISM`: remove only the named mechanism; preserve information, tools and total resource ceiling.
- `M3_RESOURCE_MATCHED_SIMPLE`: simple/direct system granted matched token/tool/wall-clock budget to M1.
- `M4_HUMAN_MIMETIC_SCAFFOLD_MATCH`: where technically meaningful, replace the native mechanism with an explicit language/linear scaffold while preserving information and resource ceilings.

If an ablation necessarily changes information access, the case is `CANNOT_CHECK_CAUSAL_ATTRIBUTION`, not evidence for the mechanism.

### Primary Phase-A endpoint

Correct registered task disposition / exact formal witness under the private oracle.

### Phase-A mechanism gate

The primary mechanism is supported only if:

1. M1 > M2 by at least 10 percentage points;
2. the paired 95% interval excludes zero under the frozen exact/paired analysis;
3. M1 also exceeds M3, so extra resource alone does not reproduce the gain;
4. M2 does not introduce a new information deficit relative to M1;
5. no critical exact-oracle regression is hidden by aggregate scoring.

Failure closes the standalone causal mechanism claim even if M1 remains better than M0.

## 5. Phase B — cross-domain restoration

Phase B executes only if Phase A passes.

Minimum three materially different test domains:

1. one formal/mathematical domain not used in Phase A;
2. one empirical scientific domain with a frozen external witness/evaluator;
3. a second empirical domain with different data/measurement semantics.

At least 30 eligible cases per domain. Domain cases and evaluation contracts are frozen before M1/M2 outcome access.

The same named mechanism must be instantiated without changing its scientific definition. Domain-specific implementation details are allowed only if frozen before outcome access and must preserve the causal contrast.

## 6. Protected Phase-B endpoint

A registered scientific decision with an external witness appropriate to the domain, such as:

- accept/block a transfer;
- choose/defer an intervention;
- retain/reopen a conclusion;
- validate/reject a formal construction;
- return unresolvedness when the evaluator is insufficient.

Internal novelty, opacity, surprise, self-rated confidence and stylistic difference are not endpoints.

## 7. Standalone P-F survival terminal

P-F may become a standalone publication candidate only if:

1. the R2 trigger fires;
2. Phase A establishes causal value of one named mechanism;
3. the same mechanism improves the protected endpoint over its matched ablation in at least two of three Phase-B domains by >=10 percentage points with paired intervals excluding zero after Holm correction;
4. the resource-matched simple control does not reproduce the gain;
5. no domain shows an increase in critical scientific failures;
6. at least one domain demonstrates a benefit that cannot be reduced to a language-visible/human-mimetic scaffold under M4;
7. independent domain adjudication accepts that the external witness is scientifically appropriate.

No single generated benchmark can grant this terminal.

## 8. Negative controls

Each phase must include at least one frozen stratum where the named mechanism is predicted **not** to help. A mechanism that improves every declared stratum indiscriminately is treated as suspect for generic capacity/resource confounding until a more specific causal account is established.

## 9. Valid contraction terminals

- `NO_R2_EFFECT_TO_EXPLAIN__P_F_STANDALONE_ROUTE_CLOSED_OR_MERGE`;
- `CANNOT_IDENTIFY_PREOUTCOME_MECHANISM`;
- `RESOURCE_MATCHED_SIMPLE_REPRODUCES_GAIN`;
- `PRIMARY_MECHANISM_ABLATION_NO_EFFECT`;
- `LANGUAGE_SCAFFOLD_REPRODUCES_GAIN`;
- `FORMAL_ONLY_NO_CROSS_DOMAIN_RESTORATION`;
- `DOMAIN_SPECIFIC_ONLY`;
- `CRITICAL_FAILURE_REGRESSION`;
- `CANNOT_CHECK_CAUSAL_ATTRIBUTION`;
- `CANNOT_CHECK_EXTERNAL_WITNESS`.

These are scientifically valid and should trigger merge/contraction rather than mechanism shopping.

## 10. Leakage / custody

Before every dispatch freeze hashes for task materials, private oracles, arm implementation, mechanism manifest, tool/model versions, resource ceilings and analysis code/specification. Private oracle answers must be absent from model-visible workspaces. Same-model repetitions are not independent replication.

## 11. Relationship to P-C and flagship

A negative P-F terminal does not damage the broader statement that machine-native computation may be scientifically useful; it only blocks the standalone causal-superiority paper. Surviving scoped principles may merge into P-C or the flagship. A positive P-F terminal does not establish a universal machine epistemics field or human inferiority.

## Authority

This is a pre-outcome protocol. It grants no scientific truth, paper admission or publication readiness before valid trigger, execution, custody and terminal receipts.
