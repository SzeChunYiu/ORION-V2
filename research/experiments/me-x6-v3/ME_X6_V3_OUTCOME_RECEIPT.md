**The V2 negative was intermediate, and this is the revival pass on it.** V2 terminated
`TYPING_NOT_SEPARATED_AT_MATCHED_CAPACITY` and attributed V1's separation to capacity. The
question V2 left open, and the falsifying test it licensed, was whether there is a generator
family in which the a-priori typed roles carry information the channels do not — where
typing is load-bearing rather than a re-description of a learnable weight vector. V3 asked
it under **role-coverage shift**: extend the generator so that every one of M's eight
declared roles is exercised alone, hold V2's learned vector frozen, and see whether the
typed assignment does something a learner could not have done from the public development
split.

learned that four roles are **unexercised on the split it saw**. Whether that is a defect of
the fitter or a property of typing is the V3 question, and it has a measurable answer.

## 5. Reading, stated plainly

**The a-priori typed assignment buys exactly what development coverage would have bought,
and nothing more.** Hold V2's learned vector fixed and shift the role coverage: it fails on
every instance of the four roles it never saw exercised (a coverage failure, not a typing
failure — the fitter was never shown them). Give the same selection rule the completed
coverage and it recovers a vector that ties M on all 1,800 instances with zero discordant
pairs, including the 400 held-out ones — and that vector is **not M's**: it is a
real-valued L1-path vector, live on `disruption` (a channel M types as zero) and with a
different sign pattern from M's integer roles. Two different rules, one learned, decide the
conjunction exactly.

So typing is a **prior about which channels carry information**. It is robust to roles a
fitter has not seen exercised — a genuine property, worth stating, and worth exactly as much
as the coverage gap it insures against. Where the development split exercises every role,
the prior carries no information the data do not. This is the falsifying test V2 named,
executed at n = 1,800 with the tie as one of two pre-registered live outcomes, and it did
not falsify: typing did not separate.

**What this does to ME-X6 as a framework component.** V1 contracted to an interpretive
framework at V2. V3 sharpens what that framework is good for: the typed collective state
is a **specification** of which observable channels are validation channels and in which
direction they count — a declaration a reader can audit — not a mechanism that extracts
something an untyped learner cannot. That is a publishable statement at earned strength,
and it is the strength at which it should be stated: a coverage prior, in a known-answer
world, on one generator family.

## 6. Saturation

Three revival levers have now been applied to the ME-X6 negative in sequence, each
attributed to one stage and each re-tested against the strongest parent with hard gates
executed:

| pass | attributed stage | lever | verdict |
|---|---|---|---|
| V1 → V2 | comparator capacity (weight class without zero) | learned capacity-matched comparator | tie 1400/1400: capacity, not typing |
| V2 → V3 | comparator coverage (roles never exercised on the split) | role-coverage completion + refit | tie 1800/1800: coverage, not typing |
| next | — | an untyped comparator at matched information, capacity **and** coverage has no remaining registered axis on this generator | **saturated** |

**Stopping criterion, named:** every axis on which the comparator could have been handicapped
— information (V1), capacity (V2), coverage (V3) — has been matched, and at each match the
tie returned. A further separation would require a generator in which the roles' semantics
carry information not present in any channel trajectory; on ME-X6's generator every role IS
a channel trajectory, so on this world no such test exists. The next lever, if any, is a
different world, and it would be a new study, not a V4.
