# Prediction Channel and Intervention Scope V1

**Issue:** #51  
**Purpose:** prevent an over-broad reading of “complete linguistic future” that would make the prospective-revision construction self-contradictory.

## 1. Problem

The paper compares:

1. adequacy for a declared linguistic prediction target; and
2. adequacy after a later evidence intervention.

If “complete linguistic future” were defined to include **all possible future exogenous evidence inputs and every resulting response/decision**, then a state exactly sufficient for that joint controlled future could already be forced to retain the provenance distinction used by the one-bit witness.

The no-certification result therefore cannot mean:

> sufficient for every conceivable future interactive input/output process.

It means sufficiency relative to a **registered linguistic prediction channel/input protocol**.

## 2. Controlled notation

Let:

- `H_t` be current history;
- `rho` be the registered reference input protocol/channel for the linguistic prediction task;
- `Y^+_rho` be the complete declared linguistic continuation under that reference protocol;
- `X` be a registered future evidence intervention from a distinct evidence/input family;
- `r` be the responsibility evaluated before and/or after that intervention.

Define predictive equivalence relative to `rho`:

\[
h\sim_{P,\rho}h'
\iff
P(Y^+_\rho\mid H=h)
=
P(Y^+_\rho\mid H=h').
\]

Let

\[
S_{P,\rho}
=[H]_{\sim_{P,\rho}}.
\]

The current paper's `S_P` should be read as shorthand for `S_{P,rho}` once the reference protocol has been declared.

## 3. Evidence intervention is not silently part of the reference target

The later event `X=x` is supplied as a registered controlled/exogenous evidence event. It is **not** silently counted as part of the passive/reference linguistic target used to declare current predictive equivalence unless the protocol explicitly says so.

The one-bit construction therefore asserts:

```text
h_A and h_B are equivalent for Y^+_rho
current responsibility action is identical
later controlled evidence x=RETRACT(A) is then supplied to both
future responsibility actions differ
```

This is coherent because provenance is irrelevant to the registered reference prediction channel but relevant under the later intervention.

## 4. Stronger controlled-state target is a parent control

If instead the representation is required to be sufficient for the **joint controlled future across every registered evidence intervention and future responsibility**, then the relevant state becomes a controlled/policy-aware predictive/information state closer to PSR/POMDP/AIS theory.

In that stronger target:

- the extra provenance bit may be required already;
- `C_stat^*`/`Omega_dyn` relative to that stronger reference can shrink to zero;
- this is not a contradiction but a different declared prediction/responsibility target.

Thus the paper does **not** prove that even a universally controlled sufficient state can fail prospective revision. It proves that adequacy for the registered current linguistic target and present decision does not certify adequacy under a later evidence process that the current predictive evaluation did not require the representation to distinguish.

## 5. Empirical protocol consequence

Every Prospective Revision Audit must freeze separately:

```text
prediction_reference_protocol rho
present_linguistic_target
current_responsibility
future_evidence_intervention_family X
future_responsibility
```

A P2 claim is invalid if the authors redefine the predictive target after seeing the later-evidence outcome.

## 6. Required controls

### Control PC-1 — prediction target includes intervention family

Construct/identify a condition whose representation is explicitly sufficient for the joint controlled target that includes the future evidence event family.

Expected result:

- the allegedly dormant distinction may become present-state-relevant;
- P2 may contract to P0/P1.

This is a positive control that the audit is responsibility/channel-relative rather than a universal memory law.

### Control PC-2 — intervention irrelevant to responsibility

Same representation/evidence plumbing, but later event does not change the registered responsibility.

Expected: maintain, not reopen.

### Control PC-3 — evidence reconstructs dormant variable

Later evidence itself reveals the missing provenance distinction.

Expected: no strong storage-based P2 attribution because re-acquisition is sufficient.

## 7. Manuscript wording rule

Preferred:

> “state sufficient for the complete declared linguistic future **under the registered reference input protocol**”

or, when brevity matters:

> “state sufficient for the registered linguistic prediction target.”

Avoid unqualified:

> “state sufficient for the complete future”

because it can be misread as controlled sufficiency over all future interventions.

## 8. Theorem scope

The no-certification theorem is a statement about **relative certification across registered tasks/channels**:

> equality on the current predictive target and current responsibility does not imply equality on a later evidence-conditioned responsibility when the later intervention distinguishes histories inside the current evaluation equivalence classes.

This is consistent with controlled-state parent theory and is not claimed as a new universal controlled-process insufficiency theorem.
