# Joint Dynamic State Optimization V1 — Tie-Aware Exact Finite Theory

**Issue:** #51  
**Purpose:** close the last conceptual gap left by the fixed-policy dynamic theory. For `ANY_OPTIMAL_ACTION` responsibilities, the state designer may choose among tied Bayes-optimal actions **and** choose the recursively updateable state jointly. In the finite deterministic setting this can be characterized exactly as action-compatible state minimization.

**Parent boundary:** the problem is closely related to classical minimization of **incompletely specified finite-state machines (ISFSMs)**, where outputs may be don't-cares/compatible sets, compatibility need not be transitive, minimum solutions need not be unique, and exact minimization is computationally hard. This file does not claim invention of compatible-state minimization. It specializes the object to a predictive base state, Bayes-optimal epistemic actions, entropy/state-rate cost, and a static-versus-dynamic optionality premium.

---

# 1. Setup

Let:

- `\mathcal H` be a finite positive-support history state set;
- `S_P(h)` be the complete-linguistic-future predictive state;
- `\mathcal X` be a finite future observation/input alphabet;
- `\delta(h,x)` be a deterministic partial history-transition function with explicit `UNDEFINED`;
- `A^*(h)` be the nonempty set of Bayes-optimal actions permitted by an `ANY_OPTIMAL_ACTION` epistemic responsibility at history `h`;
- `p(h)>0` be the registered state distribution used for average entropy cost.

A deterministic compressed state is a partition `\Pi` of `\mathcal H`; let `\Pi(h)` denote the block containing `h`.

The state must preserve the linguistic predictive state, so every admissible partition refines the `S_P` partition.

---

# 2. Static action-compatible partitions

## Definition 1 — static admissibility

A partition `\Pi` is **static responsibility-admissible** iff:

1. **predictive refinement:**

   \[
   \Pi(h)=\Pi(h')
   \implies
   S_P(h)=S_P(h');
   \]

2. **action compatibility:** for every block `B\in\Pi`,

   \[
   \bigcap_{h\in B}A^*(h)
   \neq\varnothing.
   \]

The second condition guarantees that one Bayes-optimal action can be decoded from the state for every history in the block.

Let `\mathfrak P_{\mathrm{stat}}` be the finite set of such partitions.

Define the minimum static responsibility-state cost beyond the already retained predictive state:

\[
\boxed{
C_{\mathrm{stat}}^*
=
\min_{\Pi\in\mathfrak P_{\mathrm{stat}}}
H(\Pi(H)\mid S_P).
}
\]

Because every admissible partition refines `S_P`, this is equivalently `H(\Pi(H))-H(S_P)`.

---

# 3. Theorem J1 — static partition optimum equals optimal-selector entropy

Let `\mathcal D` be all Bayes-optimal selectors

\[
\mathcal D
=
\{d:\mathcal H\to\mathcal A:
 d(h)\in A^*(h)\ \forall h\}.
\]

## Theorem J1

\[
\boxed{
C_{\mathrm{stat}}^*
=
\min_{d\in\mathcal D}
H(d(H)\mid S_P).
}
\]

### Proof — selector to partition

For a selector `d`, partition histories by the pair `(S_P(h),d(h))`. Each block lies in one predictive fibre and has the common action `d(h)` in every `A^*(h)`, so it is static-admissible. Its conditional entropy equals `H(d(H)|S_P)`.

Thus

\[
C_{\mathrm{stat}}^*
\le
\min_d H(d(H)\mid S_P).
\]

### Proof — partition to selector

Take any static-admissible partition `\Pi`. For each block choose one action from the nonempty intersection of its optimal-action sets and define selector `d` to be that action on the block. The partition generated by `(S_P,d)` is at least as coarse as `\Pi`, because different blocks may choose the same action inside one predictive fibre. Therefore

\[
H(d(H)\mid S_P)
\le
H(\Pi(H)\mid S_P).
\]

Taking minima gives the reverse inequality. ∎

This establishes `RESPONSIBILITY_DECISION_QUOTIENT_V2.md`'s selector formula without requiring a unique responsibility equivalence relation.

# 4. Dynamic action-compatible right congruences

## Definition 2 — dynamic admissibility

A static-admissible partition `\Pi` is **dynamically admissible** iff it is also a right congruence for the registered transition system:

for every block `B`, every `h,h'\in B`, and every `x\in\mathcal X`:

1. `\delta(h,x)` is defined iff `\delta(h',x)` is defined;
2. when defined,

   \[
   \Pi(\delta(h,x))
   =
   \Pi(\delta(h',x)).
   \]

Let `\mathfrak P_{\mathrm{dyn}}\subseteq\mathfrak P_{\mathrm{stat}}` denote all dynamically admissible partitions.

Define

\[
\boxed{
C_{\mathrm{dyn}}^*
=
\min_{\Pi\in\mathfrak P_{\mathrm{dyn}}}
H(\Pi(H)\mid S_P).
}
\]

A dynamically admissible partition gives a deterministic recurrent state:

- choose one common optimal action per block;
- right congruence makes the next block a well-defined function of current block and input.

Conversely, any deterministic recursively updateable state with an optimal-action decoder induces such a partition.

---

# 5. Theorem J2 — exact joint policy/state optimum

## Theorem J2

`C_dyn^*` is the minimum additional average deterministic state entropy beyond `S_P` among **all** exact recursively updateable states that may choose any Bayes-optimal action at each history.

### Proof sketch

**Any recurrent state -> admissible partition.** Equal state values must share `S_P` because predictive state must be recoverable. The state decoder's action is Bayes-optimal for every history in a fibre, so the fibre action-set intersection is nonempty. Deterministic recursive update gives right congruence. Thus its partition lies in `\mathfrak P_dyn`.

**Admissible partition -> recurrent state.** Use block identity as the state. Choose a common action from each block intersection. Right congruence defines a deterministic state update under every input. Thus every dynamic-admissible partition is implementable.

Minimizing conditional entropy over the same feasible set proves the claim. ∎

### Parent warning

This is an entropy-weighted deterministic partition form of a classical compatible-state / incompletely specified FSM minimization problem. The state-minimization substrate is not a novelty claim.

# 6. Theorem J3 — fixed-selector refinement gives an equivalent optimization route

For a selector `d\in\mathcal D`, define base label

\[
B_d(h)=(S_P(h),d(h)).
\]

Let `S_\infty^d` be the coarsest right-congruent refinement of equality of `B_d`, computed by the registered partition-refinement algorithm.

## Theorem J3

\[
\boxed{
C_{\mathrm{dyn}}^*
=
\min_{d\in\mathcal D}
H(S_\infty^d\mid S_P).
}
\]

### Upper bound

For every selector `d`, `S_\infty^d` is predictive-refining, action-compatible (all histories in a base-label class share action `d`), and right-congruent. Therefore it is dynamically admissible:

\[
C_{\mathrm{dyn}}^*
\le
H(S_\infty^d\mid S_P).
\]

Take the minimum over `d`.

### Lower bound

Take any dynamically admissible partition `\Pi`. Choose one common action per block, yielding selector `d`. Then `\Pi` refines the base label `(S_P,d)` and is a right congruence. By definition, the coarsest right-congruent refinement `S_\infty^d` is no finer than `\Pi`; hence

\[
H(S_\infty^d\mid S_P)
\le
H(\Pi(H)\mid S_P).
\]

Taking the minimum over admissible partitions gives the reverse inequality. ∎

### Consequence

The earlier fixed-policy dynamic theory is not merely an upper-bound route. **Minimizing it over all Bayes-optimal selectors solves the exact finite joint policy/state problem.**

The computational burden may be exponential/NP-hard, but the scientific object is now closed.

# 7. Dynamic epistemic optionality premium

Because

\[
\mathfrak P_{\mathrm{dyn}}
\subseteq
\mathfrak P_{\mathrm{stat}},
\]

we have

\[
C_{\mathrm{dyn}}^*
\ge
C_{\mathrm{stat}}^*.
\]

Define the **dynamic epistemic optionality premium**

\[
\boxed{
\Omega_{\mathrm{dyn}}
=
C_{\mathrm{dyn}}^*
-
C_{\mathrm{stat}}^*
\ge0.
}
\]

This is stronger and cleaner than conditioning on one arbitrarily fixed current selector. It measures the irreducible extra average state cost imposed by the requirement that **some Bayes-optimal current policy remain recursively implementable under future observations**, after optimizing over tied optimal actions.

## Zero-premium condition

\[
\Omega_{\mathrm{dyn}}=0
\]

iff at least one entropy-minimal static action-compatible state has an equally cheap dynamically admissible realization (equivalently the two minima coincide).

The static optimum need not be unique, so the condition should be stated in terms of minimum costs, not one chosen partition.

# 8. Canonical one-bit witness under joint optimization

Construct current histories `h_0,h_1` with equal probability and one predictive fibre.

At the current time, both have the same unique optimal action `a`, so

\[
C_{\mathrm{stat}}^*=0.
\]

After observation `x`, their successors have distinct unique required actions `b_0,b_1`.

Any dynamic partition merging `h_0,h_1` would require their `x` successors to occupy the same state, but that successor block would contain histories with disjoint optimal-action sets. Therefore no dynamically admissible merge exists.

Thus the dynamic optimum separates the two current histories and

\[
C_{\mathrm{dyn}}^*=1\text{ bit},
\]

so

\[
\boxed{
\Omega_{\mathrm{dyn}}=1\text{ bit}.
}
\]

The witness survives joint policy optimization because the current action is unique and the future actions conflict.

# 10. Complexity and parent ownership

Classical incompletely specified FSM minimization shows that:

- compatibility need not be transitive;
- minimum reduced machines need not be unique;
- exact minimization is computationally hard / commonly formulated through compatibles and covering/closure constraints.

Relevant historical parent families include:

- incompletely specified sequential-machine state minimization;
- compatible-state / closed-cover algorithms;
- exact binate-cover formulations;
- incomplete Moore/Mealy machine minimization.

# 12. Mechanical algorithm

For small finite machines the executor performs exact brute force.

## Static optimum

Enumerate every partition `\Pi` that:

1. refines `S_P`;
2. has nonempty optimal-action-set intersection per block.

Compute `H(\Pi(H)|S_P)` and take minimum.

## Dynamic optimum

Filter the same partitions by right-congruence transition closure. Take minimum conditional entropy.

## Independent route

Enumerate every Bayes-optimal selector `d`, run the V3 right-congruence refinement on `(S_P,d)`, calculate `H(S_\infty^d|S_P)`, and verify minimum equals brute-force dynamic optimum.

This is a strong independent consistency check of J3.
