# Examples

Replayable examples will be added only after their schemas and expected judgments are prospectively frozen.

Initial planned controls include:

- different vocabulary / same structural role;
- same vocabulary / different structure;
- observational equivalence / interventional difference;
- representation redundancy / genuine underdetermination;
- local compatibility / global obstruction;
- lower-level repair / unnecessary Jump;
- multiple interacting failures / invalid single-stage attribution.
