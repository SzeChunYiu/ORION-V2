# ORION-V2 Papers

This subtree contains **new V2-only publication candidates**. Existing ORION P1–P15 and their related papers remain owned and published from the ORION repository.

Rules:

- candidate numbering is provisional;
- no paper may claim novelty before donor saturation and strongest-parent reduction;
- each paper requires a prospective quantitative/formal protocol, evidence package, falsifiers and honest negative terminals;
- useful research engineering without incremental scientific value remains publishable only when an appropriate methods/resource contribution is independently established;
- shared theory across papers must have one explicit owner and non-duplicative claim boundaries.

See `papers/PROGRAMME_LEDGER_V0.md` for the initial candidate programme.
