# Candidate Paper Package Template

Each admitted candidate should eventually use an ORION-style package:

```text
paper-XX-slug/
  README.md
  manuscript/
  protocol/
  evidence/
  benchmark/
  checkers/
  figures/
  reviews/
  submission/
  history/
```

Only create subdirectories when they contain real artifacts.

Required top-level fields:

- identity/status and parent ledger entry;
- exact thesis and exclusions;
- V1 ownership boundary;
- strongest native parents and donor product;
- prospective discriminator/falsifiers;
- quantitative/formal model;
- protocol/evaluator/holdout identities;
- result and negative terminals;
- independent review/adoption state.
