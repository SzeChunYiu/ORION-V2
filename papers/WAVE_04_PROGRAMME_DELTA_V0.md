# ORION-V2 Paper Programme Delta — Wave 04

## Main change

Paper candidates can no longer rely on examples showing that a generalized object is expressive. They need a native-recovery corpus proving that donor-specific decisions and counterexamples survive the mapping.

## C01/C03 — donor hunting and machine reduction

Add native recovery and counterexample reflection to donor-reduction metrics. A retrieved remote donor is useful only when the machine can reconstruct a decision-preserving adapter.

## C02 — structural knowledge space

Require each relation family to recover canonical parent judgments, not merely classify authored cross-domain examples.

## C04 — end-to-end solver

The solver should invoke a generalized family only after its native or target adapter has a valid recovery receipt. A raw structural match cannot enable an action.

## C05 — Jump

A proposed representation/method jump must include a recovery receipt for old decisions plus target-native tests for newly claimed reach.

## C06 — comparability

Wave 04 gives four distinct native terminals—exact, partial, noncomparable and cannot-check—across metrology, psychometrics, politics and linguistics. These become the minimum benchmark strata.

## C07 — evidence dependence

The effective-count fixture is a non-vacuity check only. A standalone paper needs richer covariance, overlapping-dependence and calibration models.

## C08 — provenance

Recovery receipts must be component-addressable so an invalid adapter reopens only descendants using the affected component.

## C09 — performative evaluation

Static/performance winner reversal is now a required native-recovery case. Naturalistic institutional and benchmark cases remain necessary.

## C10 — opportunity discovery

A portfolio result must be judged by native domain experts on importance, falsifiability, feasibility and downstream decisions; Pareto mathematics alone does not create scientific value.

## C11 — generalization compiler

Wave 04 supplies the first recovery protocol and constructed corpus. C11 still defaults to merge unless recovery/adaptation produces a distinct theorem or protected cross-domain result.

## New paper gate

Every candidate claiming a generalized domain theory must report:

```text
native positive recovery
native hostile recovery
assumption ledger
counterexample reflection
target adaptation blocker
strongest parent comparator
naturalistic validation status
```

No new final paper identity is authorized.
