## 3. Scientific statement being reviewed

The paper does **not** claim new minimal predictive/decision/recurrent state mathematics.

It claims:

> Relative to a registered current linguistic prediction protocol `rho`, two representations can be equally adequate for the declared current prediction target and the same current responsibility decision yet differ under a distinct later evidence intervention because one retained a historical distinction and the other did not. Therefore current prediction+decision tests do not generally certify prospective revision adequacy. The paper formalizes this no-certification gap and defines a controlled representation audit.

Canonical finite witness:

```text
C_stat^* = 0 bits
C_dyn^*  = 1 bit
Omega_dyn = 1 bit
```

with a unique current action.

The claim is **not** that a state sufficient for every possible controlled future can still forget intervention-relevant information. A stronger state/target that explicitly includes the future intervention family is a mandatory parent control and may make the premium disappear.

## 4. One-step compatibility correction the reviewer should know

The paper does not treat absence of pairwise future-action collisions as sufficiency.

For a merged representation/evidence cell, the exact one-step `ANY_OPTIMAL_ACTION` criterion is the nonemptiness of the **joint acceptable-action intersection** over all histories in the cell.

Mandatory control:

```text
{a,b}, {b,c}, {a,c}
```

has all pairwise intersections nonempty but empty joint intersection.

Pairwise disjoint action sets remain easy positive failure witnesses. This correction is parent-style decision compatibility and is not claimed as mathematical novelty.

## 6. Exact distinctness question

Please answer:

> **Is the following assessment object a sufficiently non-obvious and useful synthesis to justify an independent paper at JMLR scale?**
>

The question is deliberately stricter than “is every component new?”
