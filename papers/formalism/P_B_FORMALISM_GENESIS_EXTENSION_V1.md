# P-B Formalism Genesis Extension V1

P-B already studies typed relations, composition and obstructions. Formalism Genesis adds the case where the native relation vocabulary itself is insufficient.

A successor relation formalism is admissible only when:

\[
\text{registered deficit} \land \neg\text{parent sufficient}
\]

and the candidate supplies semantic models, explicit composition/obstruction rules, predecessor recovery and a prospectively useful consequence.

The key formal failure modes are:
- non-composition of locally valid maps;
- hidden path/history dependence;
- local-to-global obstruction;
- equivalence notions that conflate distinct native decisions;
- required generalized objects outside the current relation domain.

New P-B formal result slots:
1. parent-sufficient vs genuinely new-formalism classification;
2. countermodel rate for proposed new relation laws;
3. conservative-extension / predecessor-recovery success;
4. false unification rate;
5. hidden theorem/decision gain beyond strongest formal parents;
6. proof/model-checking and implementation cost.

A new calculus or category receives no paper credit from elegance alone; it must solve a registered transport/composition problem that existing parent formalisms do not solve more simply.
