# Flagship Formalism Box V1 — When the Current Scientific Language Is Too Weak

**Intended placement:** compact main-text box or extended Methods/Supplement, depending final evidence and venue limits.  
**Status:** candidate formalism; no empirical/theoretical superiority claimed.

Machine Epistemics must distinguish failure *within* a formalism from failure *of* the formalism to represent the distinction needed for a scientific decision.

Let `q_F(x)` denote the representation of case `x` in current formalism `F` and `J(x)` a registered native judgment. Define the decision-alias set

\[
\mathcal C_F=\{(i,j): q_F(x_i)=q_F(x_j)\ \land\ J(x_i)\neq J(x_j)\}.
\]

If `C_F` is non-empty, `F` is too coarse for that registered decision family. This does not establish the need for a grand new theory: an existing parent formalism, additional observation, or one local variable may resolve the collision.

A candidate successor formalism is represented as

\[
\mathfrak F'=(\Sigma,\mathcal T,\mathcal R,\mathcal O,\mathcal A,\mathcal D,\mathcal M,\mathcal E,\mathcal K),
\]

containing primitives, types, relations, operations, axioms, derivation rules, semantic models, predecessor recovery/equivalence maps and scope/authority constraints.

Formalism invention receives scientific credit only if it:

1. repairs a prospectively registered representational deficit;
2. is not reproduced by the strongest existing mathematical/scientific parent or a simpler patch;
3. has a semantic/model witness and appropriate consistency/countermodel checks;
4. recovers valid predecessor judgments in their scope;
5. preserves old-valid hidden cases;
6. generates a prospectively frozen new proof, prediction, decision or representation advantage on hidden problems.

Historical mathematics and physics motivate—but do not prove—this programme. Galois theory shifted attention from solving individual equations to structural relations among fields and automorphisms; generalized functions made previously informal operations rigorous; category theory supplied a language for recurring mappings and naturality; geometry/tensor calculus provided the representational resources required by general relativity. Failed generalizations are equally important controls.

The candidate breakthrough sequence is therefore tested rather than assumed:

`registered deficit -> new distinction/object/representation -> relations/operations -> axioms/calculus -> semantics -> predecessor recovery -> hidden generativity -> transfer or rejection`.

A formalism that only renames known structure terminates `NO_GENERATIVE_RESIDUAL`; a mature parent that resolves the deficit terminates `PARENT_SUFFICIENT`.
