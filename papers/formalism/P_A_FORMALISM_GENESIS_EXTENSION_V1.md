# P-A Formalism Genesis Extension V1

P-A currently asks whether a remote structural donor can be found and conservatively transported. The extension adds a harder case: no retrieved donor fully represents the target distinction.

For current representation `q_F` and registered judgment `J`, define

\[
\mathcal C_F=\{(i,j):q_F(x_i)=q_F(x_j),\ J(x_i)\neq J(x_j)\}.
\]

P-A should report whether remote-parent search resolves the collision before proposing new primitives. If not, generated candidate distinctions are compared using an exact small-task hitting-set oracle and later hidden cases. A new primitive receives no credit if semantic retrieval, the strongest formal parent, or a single local variable resolves the same deficit at lower cost.

New result slots:
- collision detection recall / false alarm;
- parent-found-before-invention rate;
- minimum-distinction recovery;
- false formalism invention;
- hidden-case generalization after the new distinction;
- resource cost.

This extension strengthens P-A only if donor discovery and formalism genesis are empirically separable. Otherwise it remains part of the same structural-discovery result.
