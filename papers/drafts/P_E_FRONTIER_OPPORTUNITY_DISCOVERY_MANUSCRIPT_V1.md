# Before the Hypothesis
## Scientific Opportunity Discovery Through Surprise, Problem Finding and Prospective Value

**P-E manuscript V1 — contingent design manuscript**

**Status:** contingent candidate after the human-thinking/lived-knowledge saturation reopen. No novelty/publication authority. P-E is dropped or merged into P-C unless prospectively frozen opportunity value survives strongest-parent comparison.

## Abstract

Most scientific automation is evaluated after a question already exists: answer it, generate a hypothesis, choose an experiment or optimize a protocol. A harder upstream problem is deciding **which scientific problems should be opened at all**. Existing problem-finding, abductive reasoning, literature-based discovery, anomaly detection, Bayesian experimental design, curiosity/open-ended learning, serendipity studies, portfolio management and science-of-science methods already own major parts of this problem. We test a narrower controlled opportunity process. Candidate opportunities must be source-bound to an anomaly, contradiction, model inadequacy, unmet need, remote donor, failed procedure, unexpected encounter or missing capability. Novelty, importance, tractability, falsifiability, independence, option value and agenda authority remain separate. The V1 revision adds a low-bandwidth `EncounterBuffer` and a typed `SerendipityCandidate`: an unexpected event can be retained and connected to unresolved problems, but surprise itself is never scientific support and random novelty is not serendipity. The evaluation is prospective: candidates are generated under frozen source/tool dates and blindly adjudicated before future outcomes are known. P-E survives only if this process produces useful future research actions beyond experts and strongest parent methods without increasing false novelty, noise fixation or agenda-authority violations. Otherwise the scientific content returns to P-C as an action-selection mechanism.

## 1. The upstream problem

A solver can be excellent at answering the wrong question. Scientific productivity depends on which problems receive attention, which anomalies are ignored, which representations are reconsidered and which unexpected events are connected to unresolved needs.

Automating this stage creates severe leakage and Goodhart risks:

- select topics resembling historically successful papers;
- infer novelty from incomplete retrieval;
- optimize for reviewer excitement;
- rediscover a known problem under remote vocabulary;
- prefer questions easy for the current model;
- generate broad “interesting directions” with no source-bound obstruction;
- chase stochastic novelty that is surprising but uninformative;
- reconstruct famous accidental discoveries with future outcome knowledge;
- let a high opportunity score allocate resources or change an agenda without authority.

P-E asks whether an opportunity record plus **prospective** evaluation can control these errors.

## 2. Opportunity record V1

Each candidate binds:

- source problem/context;
- triggering observation/residual/anomaly/encounter;
- exact source identity and acquisition mode;
- current explanatory/model state;
- why the current state is inadequate;
- candidate question;
- alternative formulations;
- nearest known scholarly/scientific parents;
- structural/practice donors where relevant;
- novelty/search status;
- importance hypothesis;
- tractability/resources;
- falsifiability/discriminator;
- independence from existing agenda;
- expected information gain;
- option value if unresolved;
- noise/irrelevance risk;
- safety/authority constraints;
- known reasons not to pursue;
- expiry/revisit conditions.

No scalar opportunity score can erase these coordinates.

## 3. Opportunity sources

### 3.1 Contradiction

Two supported claims or predictions cannot both hold under the declared scope.

### 3.2 Model inadequacy

Residual structure remains after fitting/explanation.

### 3.3 Non-identifiability

Current observations cannot distinguish scientifically different hypotheses. The opportunity may be a new measurement rather than a new theory.

### 3.4 Search gap

A decisive source, domain, source mode or representation is unexamined.

### 3.5 Remote structural donor

Another field or practice exposes a method/distinction missing from the current problem.

### 3.6 Unmet need / capability gap

A declared task cannot be executed because a measurement, dataset, tool, competence or representation is missing.

### 3.7 Evaluation failure

A benchmark/evaluator cannot distinguish important alternatives.

### 3.8 Performative response

Deployment/publication changes the environment, creating a new question.

### 3.9 Unexpected encounter

An observation was not sought by the active plan but is surprising relative to a current model or relevant to another unresolved problem.

### 3.10 Failure residue

A failed experiment/procedure contains structured residual information whose value is not exhausted by diagnosing the original failure.

## 4. Abduction without acceptance

Peircean abduction provides a useful decomposition: surprising evidence can motivate explanatory hypotheses, but the hypotheses require consequences and tests before acceptance.

P-E therefore separates:

`encounter/anomaly -> abductive portfolio -> discriminator -> evidence update`.

The portfolio is a proposal object. Plausibility, fluency or self-generated explanation is not corroboration.

A problem formulation can also change. Deweyan inquiry and modern problem-solving research warn that an indeterminate/problematic situation is not always correctly represented at the outset. P-E may therefore propose a **new problem frame**, but if the new frame changes the success criterion or target decision it receives a new comparison identity. Reframing cannot retroactively turn a failed old problem into a successful one.

## 5. Serendipity as encounter plus recognition plus follow-up

Historical accounts of serendipity support heterogeneous mechanisms rather than one universal “accident rate”. The machine-relevant object is:

`SerendipityCandidate = (encounter, unexpected_relative_to, source_identity, anomaly_type, candidate_cross_problem_value, recognition_reason, discriminator, cost, authority)`.

A candidate becomes interesting only when:

1. the event is retained with source identity;
2. the system can state why it was unexpected;
3. there is a concrete connection to an unresolved problem or possible new problem;
4. a discriminator/follow-up exists or the absence is explicit;
5. agenda authority remains external.

The system must be able to discard or downweight repeatedly uninformative novelty.

## 6. EncounterBuffer

A low-bandwidth buffer can retain a bounded subset of off-path events:

- unexpected side effects;
- structured residuals;
- failed experiments with reproducible anomalies;
- observations inconsistent with a current model;
- remote source/practice structures encountered during another search.

Periodic matching:

`EncounterBuffer × OpenProblemGraph -> CandidateLinks`.

### Control constraints

- retention budget is predeclared;
- stochastic unpredictability is not automatically high priority;
- duplicate/repeated noise is compressed;
- cross-problem matching is evaluated prospectively;
- hypotheses generated from the buffer carry no extra truth authority;
- restricted/custodial sources preserve access limits.

## 7. Exploration versus exploitation

Scientific agents can become locally efficient by repeatedly exploiting the same sources, models and methods. This can narrow the discovery frontier.

P-E separates exploration signals:

`ExplorationSignal = (novelty, predictive_surprise, uncertainty, information_gain, learning_progress, option_value, cross_problem_relevance, noise_risk)`.

The paper does not propose one universal weighting. It asks whether maintaining plural signals and an explicit exploration budget improves future opportunity value without unacceptable distraction.

### Candidate failure classes

- `EXPLORATION_COLLAPSE` — efficient exploitation destroys routes needed for later discoveries;
- `NOISE_CURIOSITY_TRAP` — unpredictability consumes attention without reusable learning;
- `SURPRISE_SUPPRESSION` — an inexpensive, potentially discriminating off-path event is discarded solely because it was unplanned;
- `RETROSPECTIVE_SERENDIPITY_LEAKAGE` — future outcome knowledge contaminates opportunity scoring.

## 8. Core separations

### Novelty

Whether the opportunity is already known. `NO_PRIOR_ART_FOUND` is not proof of novelty.

### Importance

Potential scientific consequence if resolved.

### Tractability

Probability available resources can make progress.

### Falsifiability/discriminability

Whether a decisive or materially informative observation is conceivable.

### Independence

Whether the opportunity adds a new decision/relation rather than repackaging an existing agenda item.

### Option value

Whether preserving the opportunity for later has value even if immediate execution is weak.

### Serendipity value

Whether an unexpected encounter opens a useful, testable connection; distinct from novelty itself.

### Authority

Whether the system may add, prioritize, fund, execute or publish the opportunity. A model-generated opportunity cannot self-authorize an agenda.

## 9. Parent threats

- problem-finding research in creativity/design;
- Peircean abduction and discovery systems;
- literature-based discovery;
- anomaly/outlier detection;
- active learning and Bayesian experiment design;
- curiosity/intrinsic motivation;
- novelty search/open-ended learning;
- exploration–exploitation theory;
- serendipity studies and information encountering;
- bandits/portfolio selection;
- R&D/innovation management;
- science-of-science forecasting/opportunity mapping;
- research-priority setting and technology roadmapping.

P-E survives only if **source-bound opportunity state + prospective evaluation + authority separation** adds value beyond the strongest composition of these parents.

## 10. Prospective protocol

Retrospective evaluation is too vulnerable to hindsight.

### Phase 1 — Freeze information

Choose several research areas with active experts. Freeze:

- literature/source cutoff date;
- non-paper source access;
- tools/models;
- search budget;
- candidate-generation algorithm;
- parent baselines;
- encounter-buffer retention rules.

### Phase 2 — Blind initial adjudication

Experts, blinded to system identity, separately rate:

- known/duplicate status;
- importance;
- tractability;
- falsifiability;
- independence;
- required resources;
- whether the question should enter a real research queue;
- whether the trigger/connection is understandable without outcome knowledge.

### Phase 3 — Bounded follow-up

Track candidates under a predeclared horizon. Do not remove negative, blocked, duplicate or unresolved candidates from analysis.

### Phase 4 — Re-evaluation

Measure whether initial judgments predicted useful scientific actions/results and whether the typed opportunity record improved decision reproducibility or contraction.

## 12. Metrics

Primary prospective:

- expert queue-admission rate;
- duplicate/known-problem rate;
- actionable discriminator rate;
- prospective scientific-value rating;
- later useful-action/result rate;
- false novelty rate;
- useful encounter-recognition rate;
- false surprise/noise fixation rate;
- authority/agenda violation rate;
- inter-expert reproducibility.

Secondary:

- candidate-generation cost;
- time to first decisive action;
- diversity across problem/source classes;
- option value of deferred candidates;
- fraction blocked by missing resources;
- successful novelty contraction;
- exploration budget consumed by nonproductive events.

## 13. Hostile controls

### H1 — Famous-but-solved lure

Important/popular problem already resolved. Do not rank as novel.

### H2 — Retrieval censorship

Literature or community source inaccessible. Novelty becomes `CANNOT_CHECK`.

### H3 — Easy-but-trivial lure

High tractability, low scientific value.

### H4 — Exciting-but-unfalsifiable lure

Broad speculation with no discriminator.

### H5 — Remote known parent

Lexically new, structurally owned elsewhere.

### H6 — Useful practical donor, no scholarly novelty

A manual/recipe suggests a research-control structure already scientifically understood in another parent field. Contract the scientific novelty claim.

### H7 — Noise curiosity trap

Stochastic events are highly surprising but have no reproducible/cross-problem structure.

### H8 — Genuine prospective encounter

An off-path event has a cheap discriminator and later proves useful. Score based on the frozen pre-outcome record, not hindsight.

### H9 — False serendipity storytelling

Outcome is revealed first, then the system reconstructs why an earlier event was “obviously” important. This arm should fail prospective validity.

### H10 — Agenda authority lure

A high-value opportunity cannot self-allocate protected resources.

## 14. Relationship to P-C

P-E is upstream of the solver: it changes which problems can enter the active queue. But the boundary is deliberately strict.

If the only robust benefit is choosing a next action inside an existing problem, the mechanism belongs to P-C. If prospective opportunity discovery does not beat experts/parents, P-E should disappear as a standalone paper.

## 17. Survival gate

P-E remains a standalone Article only if a prospectively frozen study demonstrates useful future research value beyond strongest parent methods and expert/direct controls, with separately calibrated novelty, tractability, falsifiability, serendipity value and authority.

Until then the default scientific action is contraction, not publication persistence.
