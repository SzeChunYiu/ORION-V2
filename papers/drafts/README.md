## Shared release gate

Every paper must preserve:

1. exact V1 ownership/non-overlap;
2. strongest parent-composed comparator;
3. quantitative/formal discriminator;
4. protected hostile/simple controls;
5. non-compensatory validity/integrity outcomes;
6. honest negative and `CANNOT_CHECK` terminals;
7. independent/protected evaluation before scientific or publication claims;
8. fail-closed atomic claim verification;
9. claim-driven figure evidence;
10. exact live journal/content-type compliance immediately before submission.

Writing completion is never a substitute for scientific evidence.
