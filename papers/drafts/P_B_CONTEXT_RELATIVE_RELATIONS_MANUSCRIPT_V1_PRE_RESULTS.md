# Scientific Relations Are Context-Relative
## Typed Transport, Obstruction and Selective Reopening Across Heterogeneous Scientific Representations

**Paper ID:** P-B  
**Status:** theory/method manuscript complete before protected cross-parent outcomes.  
**Primary target hypothesis:** Nature Computational Science Article.  
**Fallback:** Artificial Intelligence.  
**Novelty boundary:** bounded propositions below are parent-style consequences; standalone scientific credit depends on protected cross-parent decision value.

## Abstract

Scientific representations can be “the same” in fundamentally different senses: observationally indistinguishable yet interventionally different, decision-equivalent yet information-different, comparable under one measurement standard but not another, or exactly related for one query while unsafe for future use. We study whether a common typed interface can coordinate these relations without replacing their native mathematics. The proposed representation binds a relation family to a declared context, direction, witnesses, preserved decisions, approximation or measurement loss, counter-probes, epoch and revalidation consequences. We provide bounded formal propositions for context refinement, exact decision-preserving composition and selective reopening under explicit support-family semantics; these are not claimed as new general mathematics. The protected benchmark compares the interface with the strongest parent-specific relation methods and parent compositions on cross-family known-answer and hostile cases. Standalone value is earned only if the shared interface changes valid reuse or reopening decisions while preserving native judgments. Parent sufficiency, purely administrative interoperability and formal contraction are predeclared outcomes. Numerical/benchmark results remain protected and are not asserted here.

# 1. Introduction

“Are these two things equivalent?” is an incomplete scientific question.

Two causal models can be observationally equivalent but imply different interventions. Two statistical experiments can support the same current decision while retaining different information. Two physical measurements can be traceable yet not comparable for the intended use. Two programs can be behaviourally equivalent under one interface but differ under another. Two abstractions can preserve a present query while destroying a future one.

This plurality creates a problem for machine-mediated science. Retrieval and embedding systems often produce one generic similarity surface, while scientific reuse depends on a relation family, a context and a decision. A machine that turns “similar” into “transportable,” or “predictively equivalent” into “causally equivalent,” can produce scientifically invalid reuse even when its representation is internally coherent.

P-B asks:

> **Can a shared typed relation interface coordinate heterogeneous scientific notions of sameness, comparability and transport while preserving parent-native judgments—and does that coordination change protected scientific reuse or reopening decisions beyond the strongest parent composition?**

The null is strong. Mature parents may already suffice when composed carefully. In that case the shared interface is engineering infrastructure, not a new scientific theory.

# 2. Parent sciences and claim ceiling

The paper's core warning is already encoded in many mature disciplines.

Causal inference distinguishes observational equivalence from interventional or transport equivalence. Statistics and decision theory distinguish information from decision sufficiency and compare experiments by their usefulness for decisions. Psychometrics and metrology study measurement invariance, calibration and traceability. Formal methods study bisimulation, contextual equivalence, abstract interpretation, refinement and safe quotienting. Markov-chain lumpability and computational mechanics provide additional state-abstraction notions. Rough sets formalize indiscernibility relative to available attributes. Category theory provides composition and naturality only when native categorical structure exists. Sheaf/local-to-global methods and constraint systems study compatibility and obstruction.

P-B therefore does **not** claim:

- one universal equivalence relation;
- one scalar similarity score that subsumes native parents;
- that causal, observational, formal, measurement or decision relations are interchangeable;
- that a common receipt format is a new theorem;
- that category theory is universally appropriate;
- that an internally elegant composition is empirically valid without empirical evidence.

The possible residual is an independently useful **scientific control interface** for choosing relations, preserving type/loss information, rejecting invalid composition and determining downstream reuse/reopening.

# 3. Relation object

Let a scientific context be

\[
C=(Q,I,D,B,K,T,\epsilon),
\]

where:

- `Q` — registered queries/predictions;
- `I` — interventions or transformations;
- `D` — decisions/actions;
- `B` — resource/budget constraints;
- `K` — constitutional/authority constraints;
- `T` — target and epoch/anchor;
- `epsilon` — registered tolerance/error semantics.

A relation receipt is

\[
R=(S_1,S_2,\mathcal F,C,W,L,X,E,A),
\]

where:

- `S1,S2` are native scientific objects/representations;
- `F` is the relation family;
- `C` is context;
- `W` are witnesses;
- `L` are losses/approximation/deficiency terms;
- `X` are counter-probes/obstructions;
- `E` is epoch/expiry/revalidation state;
- `A` is authority/provenance boundary.

The receipt does not create the relation. It exposes the parent theory and the conditions under which the relation may be used.

# 5. Typed mapping and obstruction

For an eligible source/target pair, a candidate structural mapping may be represented as

\[
\phi=(\phi_V,\phi_R):\mathcal S_S\rightharpoonup\mathcal S_T.
\]

Define a non-compensatory violation vector

\[
\mathbf e(\phi)=
(e_{type},e_{rel},e_{direction},e_{inv},e_{approx},e_{measurement},e_{scope},e_{authority}).
\]

A critical violation blocks exact transport even if semantic similarity is high.

When a registered transformation `g` should preserve decision `J`, test invariance

\[
J(gx)=J(x),
\]

or lawful equivariance

\[
J(gx)=\rho(g)J(x).
\]

Categorical or commuting-diagram tests are permitted only when source and target genuinely instantiate the relevant categorical objects/morphisms. Formal success cannot establish an empirical transport assumption.

Define the obstruction set

\[
\Omega(\phi)=\{c\in C(\phi): c\text{ fails in the target}\}.
\]

A registered critical obstruction blocks the corresponding transport disposition.

# 6. Bounded formal propositions

The following propositions close parts of PB-C4 under explicit semantics. They are elementary or parent-style results and do **not** establish a new general relation calculus.

## Proposition 1 — context refinement

Let a context-relative equivalence `~_C` mean that two objects agree on **all** registered judgments in context `C`. Suppose context `C_2` refines `C_1` by containing every query/intervention/decision obligation in `C_1` and possibly more, with identical semantics for shared obligations.

Then

\[
x\sim_{C_2}y
\Rightarrow
x\sim_{C_1}y.
\]

### Proof

Agreement on every obligation in the larger set implies agreement on every obligation in its subset. ∎

### Boundary

The converse is false in general. An abstraction safe for a current context need not be safe for a future richer context.

This proposition is a bookkeeping consequence of decision-relative equivalence, not a novel theorem.

---

## Proposition 2 — exact decision-preserving composition

Let

\[
f:S_1\to S_2,
\qquad
g:S_2\to S_3
\]

be mappings. Let `J_1,J_2,J_3` be registered decision functions such that for all relevant `x`,

\[
J_2(f(x))=J_1(x),
\]

and for all relevant `y`,

\[
J_3(g(y))=J_2(y).
\]

Then the composition preserves the registered decision:

\[
J_3(g(f(x)))=J_1(x).
\]

### Proof

Substitute the first equality into the second:

\[
J_3(g(f(x)))=J_2(f(x))=J_1(x).
\]

∎

### Boundary

This does **not** imply composition of causal, measurement, semantic or authority validity beyond the registered decision. Approximate relations require a lawful parent error-composition rule; errors do not automatically cancel or remain bounded.

---

## Proposition 3 — selective reopening under sufficient-support-family semantics

Let a claim `q` have a finite collection of complete sufficient support families

\[
\mathcal H_q=\{H_1,\ldots,H_m\}.
\]

Assume `q` is currently supported iff at least one complete family is entirely valid:

\[
\mathrm{Supported}(q)
\iff
\exists H_j\in\mathcal H_q\;:\;H_j\cap I=\varnothing,
\]

where `I` is the set of invalidated support elements after a source/relation/evaluator change.

Then `q` must reopen iff every complete sufficient family contains an invalidated element:

\[
\boxed{
\mathrm{Reopen}(q,I)=1
\iff
\forall H_j\in\mathcal H_q,
\;H_j\cap I\neq\varnothing.
}
\]

### Proof

By the support semantics, `q` remains supported exactly when there exists a family with empty intersection with `I`. Negating this existential gives that every family has nonempty intersection with `I`. ∎

### Boundary

The theorem is exact only for the declared sufficient-family semantics. Real scientific support may be graded, probabilistic, nonmonotonic or institutionally constrained; those cases require their native parent semantics.

---

## Proposition 4 — monotone invalidation under exact sufficient-family semantics

Under Proposition 3's semantics, if

\[
I_1\subseteq I_2,
\]

then any claim reopened under `I_1` remains reopened under `I_2`.

### Proof

If every sufficient family intersects `I_1`, then every family also intersects its superset `I_2`. ∎

### Boundary

This proposition does not apply when later evidence creates a new sufficient support family or repairs an invalid member. The state transition then changes `H_q`, not merely `I`.

# 7. Benchmark families

## 7.1 Known-answer relation cases

Each case has a native parent and exact/accepted native verdict where feasible.

Required hostile distinctions include:

- observationally same / interventionally different;
- predictively same / decision-different;
- decision-equivalent / information-different;
- same role / different semantics;
- measurement-traceable / not fit-for-purpose comparable;
- exact versus approximate transport;
- local compatibility / global obstruction;
- current-context safe / future-context unsafe;
- valid relation whose epoch/anchor expires;
- genuinely incomparable objects.

## 7.2 Cross-parent cases

Cases should require selecting the appropriate parent rather than merely applying a supplied relation label.

## 7.3 Composition cases

Include:

- valid exact composition;
- invalid composition because direction/type changes;
- approximate composition with accumulating error;
- composition that preserves current decision but loses another registered query;
- formally commuting relation that lacks empirical support.

## 7.4 Reopening cases

Support graphs include:

- one sufficient path invalidated;
- one of several independent sufficient paths invalidated;
- all sufficient paths invalidated;
- common ancestor invalidates several descendants;
- new support arrives after reopening;
- evaluator epoch changes but source evidence remains.

# 12. Discussion branches

## If cross-parent decision residual survives

Frame the contribution as a typed **coordination and validity interface**, not a universal equivalence theory. Emphasize the decisions that parent-local components could not safely coordinate under the frozen setup.

## If parent federation matches

Conclude that native parent routing plus explicit metadata is sufficient. Preserve benchmark and reopening formalization as an engineering/resource result.

## If formal propositions hold but empirical residual fails

Do not upgrade formal correctness into scientific efficacy. The paper may contract to a formal methods/interface resource or merge into the flagship.

## If relation selection is accurate but reopening is not

Separate the relation-classification problem from support/dependence semantics rather than forcing one unified paper.

# 13. Limitations

1. Context must be declared; relation truth is not context-free for most scientific reuse questions.
2. Native parent selection can itself be difficult and may require experts.
3. Some empirical relations cannot be decided from finite observational data.
4. Approximation errors can interact nonlinearly; parent-specific bounds are required.
5. Support-family semantics in Proposition 3 are deliberately idealized.
6. Authority/provenance constraints can block action even when scientific transport is valid.
7. A common interface can create false confidence if users mistake schema uniformity for semantic uniformity.
