- experimental design;
- code and test generation;
- manuscript drafting and editing.

Current top-tier policies permit substantial assistive/evaluative AI use only with transparent disclosure, verification and demonstrable human-led scholarly judgment. Human authors therefore need to do more than approve prose.

## 5. Source/citation review

- [ ] source read directly rather than only through an AI summary;

## 6. Results review

For every headline result:

- [ ] raw/case-level or exact receipt inspected;
- [ ] invalid runs separated from scientific outcomes;
- [ ] uncertainty/statistical method verified;

- [ ] figure/table regenerated from frozen data/receipt;
