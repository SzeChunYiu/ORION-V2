## 6. Shared result-import algorithm

For every paper:

```text
read frozen result schema
-> locate immutable result receipt
-> validate protocol/data/analysis identities
-> import estimate/terminal/uncertainty only
-> regenerate dependent table/figure/prose
-> select prewritten Discussion branch
-> run atomic-claim verification
-> run citation entailment
-> run figure/display contract
-> run manuscript-surface QA
-> build arXiv package
-> human release approval
-> journal adapter
```

## 7. Prohibited actions

The executor must not:

- invent a missing result;
- turn `CANNOT_CHECK` into a failure or success;
- use nonsignificance as equivalence;
- change an independent unit;
- aggregate away a critical failure;
- remove a parent win;
- add a new mechanism after seeing outcomes;
- create a new paper identity to preserve a positive narrative;
- select author list, legal license, COIs or publication authority.
