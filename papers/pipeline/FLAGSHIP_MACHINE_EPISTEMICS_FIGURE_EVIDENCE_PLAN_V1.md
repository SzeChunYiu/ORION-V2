## Figure 1 — Scientific-state transitions in an executable research episode

### Reader question

**What exactly is the new object of study, and why is an AI workflow diagram insufficient?**

### Claims supported

- AI/hybrid research processes increasingly consist of persistent sequences of search, computation, experiment, interpretation and revision.
- execution output and scientific-state transition are distinct objects;
- the same execution can produce different scientific consequences under different evidence/semantic/authority conditions.

### Visual object

A bounded **Machine-Epistemic Episode** with:

- left boundary: problem/criterion contract and initial plural scientific state;
- middle: admissible actions (retrieval, proof/computation, simulation, experiment/measurement, human review);
- outputs: observations/tool results;
- interpretation/transition gate;
- right: updated scientific state + reopened obligations/history.

Four small hostile examples sit below the main transition:

1. execution succeeds, evidence link invalid;
2. provenance/replay exact, scientific analysis wrong;
3. three agreeing validators share a hidden source;
4. local search flat but a route is censored.

### Evidence basis

Published autonomous-research systems establish that multi-step scientific processes are becoming machine-mediated. The four failures are conceptual known-answer distinctions, not claimed empirical prevalence estimates.

### Strongest alternative to expose

**Alternative:** this is merely a generic agent/workflow state machine.

**Visual discriminator:** a normal workflow arrow ends in output; the Machine-Epistemic figure inserts a scientifically typed interpretation/transition gate and shows obligations/reopening after the action.

### Main/support decision

**Main Figure 1.** Necessary to define the object and prevent readers from interpreting the field as agent orchestration.

## Figure 2 — Parent ownership and the composition gap

### Reader question

**What do existing fields already own, and what—if anything—is left for Machine Epistemics?**

### Claims supported

- most component mechanisms are mature parents;
- the proposed field does not own generic epistemology, control, metareasoning, diagnosis, provenance, causal transport, measurement or AI for Science;
- the field hypothesis concerns a small set of cross-layer scientific-transition decisions.

### Visual object

A matrix rather than a “Machine Epistemics contains everything” Venn diagram.

Rows: parent fields/traditions.

Columns: native scientific decisions/functions, for example:

- reliable learning / identifiability;
- action/experiment selection;
- belief dependency/revision;
- diagnosis/discrimination;
- exact/approximate relation and transport;
- measurement/linking;
- provenance/replay;
- evidence combination;
- evaluator response;
- institutional/normative authority;
- end-to-end scientific automation.

A final narrow column lists candidate **composition gaps** only where multiple rows must interact:

- provenance -> scientific validity;
- relation -> downstream reuse/reopening;
- evidence -> authority-bounded adoption;
- route stop -> scientific closure;
- local repair -> search-space escalation.

### Evidence basis

Each row must have direct canonical source(s), not only broad reviews. The final matrix requires a completed citation-entailment audit.

### Strongest alternative to expose

**Alternative:** mature parents already cover every proposed gap in straightforward composition.

**Visual discriminator:** every composition-gap cell has an explicit `parent composition may suffice` symbol. The figure is designed to permit field falsification.

### Main/support decision

**Main Figure 2.** This is the anti-columbusing evidence unit and is publication-critical for a field-defining Perspective.

## Figure 3 — Four control problems of Machine Epistemics

### Reader question

**If the field hypothesis survives, what compact set of questions organizes its research?**

### Visual object

Four linked quadrants around a bounded research episode:

1. **Observe epistemic state**
   - What is distinguishable?
   - What evidence/routes/dependencies are visible?
   - What is structurally non-identifiable?

2. **Control and transport transitions**
   - What commitment may change?
   - What survives representation/context/epoch change?
   - What must reopen?

3. **Assure evidence and authority**
   - Which support is independent?
   - Which evaluator remains valid?
   - What external authority boundary applies?

4. **Govern escalation and closure**
   - Is a lower-level repair sufficient?
   - When must search/model/representation change?
   - What bounded evidence licenses stopping?

Each quadrant contains:

- 2–3 canonical parent methods;
- one cross-layer failure example;
- 2 measurable research quantities.

### Candidate quantitative quantities

- state/failure distinguishability or minimum probe cost;
- false/unsafe transport rate;
- support calibration under dependence;
- false/missed escalation;
- false closure under censored routes;
- unnecessary refusal/over-conservatism.

### Strongest alternative to expose

**Alternative:** the four questions are an arbitrary private taxonomy.

**Visual discriminator:** every problem is tied both to mature parents and to an observable scientific decision/failure metric. Cross-domain studies must be able to instantiate the same four questions without ORION terminology.

### Main/support decision

**Main Figure 3.** This is the field's compact organizing device, analogous in role—not layout—to the small principle/dimension frameworks used by strong field Perspectives.

## Figure 4 — Falsifying the field hypothesis

### Reader question

**What evidence would show that Machine Epistemics is a distinct scientific programme, and what evidence would make us abandon the field claim?**

### Visual object

A decision/evidence path:

`native parent reconstruction`
→ `strongest information-matched parent composition`
→ `protected cross-domain transition cases`
→ `independent evaluation`
→ one of:

- `stable cross-domain residual` — field hypothesis strengthened;
- `parent tie / parent win` — integration engineering;
- `domain-specific only` — return to native parent;
- `cannot independently adjudicate` — field separation unresolved.

### Evidence basis

This is a prospective methodological/falsification schematic, not a plot of results.

### Main/support decision

**Main Figure 4 if target length/display budget permits; otherwise Box/Extended conceptual display.** It materially distinguishes the manuscript from promotional manifestos by making field failure inspectable.
