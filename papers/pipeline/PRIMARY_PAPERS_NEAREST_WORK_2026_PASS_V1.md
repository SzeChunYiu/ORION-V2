# P-A — structural transfer discovery

## Direct recent parents

### Unlocking LLM Creativity in Science through Analogical Reasoning (2026)

Andrew Shen, Shaul Druckmann, James Zou. Public 2026 preprint, arXiv:2605.11258.

- explicitly applies analogical reasoning to open-ended scientific solution generation;
- retrieves/generates cross-domain analogies using shared relational structure;
- reports increased diversity/novelty and implements generated solutions on biomedical problems.

### ResearchBench (ACL Findings 2026)

*ResearchBench: Benchmarking LLMs in Scientific Discovery via Inspiration-Based Task Decomposition.*

Public result/claim surface:

- decomposes scientific discovery into inspiration retrieval, hypothesis composition and ranking;
- reports LLM strength on inspiration retrieval;
- uses newer papers to reduce contamination and supports renewable evaluation.

### Analogical Deep Research / CANA (2026)

*Analogical Deep Research: Retrieving and Integrating Historical Analogies for Foresight Analysis*, arXiv:2607.13602.

Public result/claim surface:

- explicitly benchmarks finding and using remote historical analogies;
- diagnoses surface-feature matching versus underlying mechanisms;
- proposes mechanism alignment, structural decomposition and cross-analogy confirmation;
- reports gains over deep-research agents.

### ReTRE (ACL 2026)

*ReTRE: Benchmarking LLM Transfer Robustness with Structure-Preserving Variants*, ACL 2026.

Public result/claim surface:

- constructs near/far structure-preserving variants in mathematical and scientific tasks;
- finds substantial far-transfer robustness gaps.

- *Can Large Language Models Generalize Analogy Solving Like Children Can?*

Public system surface includes autonomous idea generation, literature search, tree-based experimentation, coding, result analysis, paper writing and automated reviewing.

Robin coordinates literature analysis, question decomposition, hypothesis generation, assay planning, ranking and experimental validation with substantial automation.

An LLM-driven agent plans instrument actions, executes commands, interprets observations and adapts to unexpected experimental conditions in a real beamline deployment.

Current systems/benchmarks already evaluate complete experimental workflows and adaptive agent behavior.


# P-D — dependence-aware evidence and dynamic evaluation

## Direct current multi-agent/evaluator pressure

### On the Reliability Limits of LLM-Based Multi-Agent Planning (2026)

Public preprint theorem surface:

- delegated multi-agent networks using shared information and no new exogenous signal are decision-theoretically dominated by a centralized Bayes decision maker with the same information;
- communication/compression loss can be characterized under proper scoring rules.

This is a strong parent against claims that agent multiplicity itself creates information or reliability.

### The Consistency Illusion (2026)

Public preprint reports that multi-agent answer agreement can mask reasoning misalignment; consensus is therefore not a sufficient reliability measure.

### Reward Hacking as Equilibrium under Finite Evaluation (2026)

Public preprint argues that finite evaluators create systematic optimization pressure toward uncovered quality dimensions, with stronger risks in agentic systems.

### Production/evolving evaluation (AlphaEval 2026)

Public preprint emphasizes production agent tasks with heterogeneous inputs, implicit constraints and domain-expert standards that evolve over time, using multiple evaluation paradigms.

These works are direct pressure on the P-D motivation and should be cited/compared if their full texts support the final sentences.

## P-D contraction

P-D must not claim:

- first warning that multi-agent consensus is unreliable;
- first information-theoretic limit on shared-evidence multi-agent systems;
- first observation that reasoning paths can disagree despite answer consensus;
- first theory of finite-evaluator reward/evaluation hacking;
- first production-agent evaluation with changing standards.

### Surviving candidate residual

P-D's candidate contribution is narrower:

```text
scientific evidence dependence topology
+ evaluator error-class/sensitivity identity
+ explicit environment/evaluator epoch response
+ protected selective-reopening/authority decisions
+ strongest separate parent-pipeline control
```

The joint assurance object earns a standalone paper only if it changes a scientific decision beyond applying dependence and dynamic-evaluation parents separately.
