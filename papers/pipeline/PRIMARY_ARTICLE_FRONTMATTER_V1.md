# Primary Article Frontmatter V1

**Papers:** P-A, P-B, P-C, P-D  
**Target constraint:** Nature Machine Intelligence / Nature Computational Science Articles currently allow abstracts up to 150 words.  
**Status:** pre-results frontmatter. These are not submission abstracts until the protected result sentence is populated from frozen receipts.

## General rule

Final abstract structure:

1. scientific problem;
2. method/design;
3. **protected result sentence generated only from registered receipts**;
4. bounded interpretation / negative-result-compatible claim.

The result sentence may not be written from desired outcome. If the primary terminal is parent sufficiency/no residual/CANNOT_CHECK, the abstract must say so.

# P-A

## Title

**Discovering Remote Scientific Structure Without Losing Native Meaning**

Alternative, if editors prefer explicit method scope:

**Structural Donor Discovery with Native Scientific Fidelity**

## Pre-results abstract — 142 words

Scientific discovery can depend on ideas developed in remote domains, yet topical search and generic analogical retrieval can confuse structural relevance with surface similarity. We study a protected transfer process that separates donor discovery, native reconstruction, bounded structural mapping, counter-probes and novelty contraction. Hidden scientific donors and native judgments are withheld from solver arms. The candidate process is compared under matched information and resources with lexical/citation search, semantic retrieval, literature-based discovery, analogy methods, fixed lessons, applicable formal parents, experts and their strongest federation. Primary outcomes jointly measure remote-donor recovery, critical false analogy, donor-native fidelity, target-decision quality, correct parent contraction and resource cost. Recent scientific-analogy and inspiration-retrieval systems are treated as direct parents rather than weak baselines. Parent sufficiency, unsafe recall gains and no scientific residual are preregistered outcomes. Protected numerical results will determine whether the integrated process merits an independent method claim.

## Final abstract result slot

Replace the last sentence with **one** receipt-derived sentence, e.g. according to terminal:

```text
PROTECTED_TRANSFER_RESIDUAL:
  Under matched budgets, the integrated process [effect with uncertainty] while [critical false-analogy/native-fidelity statement].

PARENT_SUFFICIENT:
  The strongest parent federation matched the integrated process on protected scientific decisions at [cost relationship], providing no independent transfer residual.

REMOTE_RECALL_GAIN_FALSE_ANALOGY_TOO_HIGH:
  The integrated process increased remote recovery but exceeded the frozen critical false-analogy threshold, so no scientific transfer advantage was supported.

CANNOT_CHECK:
  Protected comparison could not determine an independent residual because [registered missing/infrastructure/evaluator reason].
```

# P-B

## Title

**Scientific Relations Are Context-Relative**

Subtitle for manuscript:

**Typed Transport, Obstruction and Selective Reopening Across Heterogeneous Scientific Representations**

## Pre-results abstract — 137 words

Scientific representations can be equivalent for one purpose and incompatible for another. We study whether a typed interface can coordinate causal, predictive, decision, formal, measurement and transport relations without replacing their native semantics. The interface binds each relation to a declared context, direction, witnesses, losses, counter-probes, epoch and reopening consequences. We prove bounded propositions for context refinement, exact decision-preserving composition and selective reopening under explicit sufficient-support semantics, while treating these as parent-style results rather than a new general calculus. A protected cross-parent benchmark compares the interface with strongest native-parent selection and parent federation on known-answer, hostile composition and reopening cases. Primary outcomes are native-verdict preservation, unsafe reuse, missed valid reuse, obstruction detection, selective reopening, calibrated CANNOT_CHECK and resource cost. A standalone paper is supported only if the shared interface changes protected scientific decisions beyond strongest parent composition.

## Final abstract result slot

The final two clauses must be replaced/augmented with one terminal-bound result sentence:

```text
CROSS_PARENT_RELATION_RESIDUAL:
  The interface changed [registered reuse/reopening outcome] beyond the strongest parent composition while preserving [native-verdict metric].

FORMAL_INTERFACE_ONLY / PARENT_SUFFICIENT:
  Native-parent composition reproduced the protected reuse/reopening decisions, leaving the typed representation as an interoperability/formal resource rather than an independent scientific mechanism.

FORMAL_CLAIM_CONTRACTED:
  Counterexamples restricted the proposed relation law to [scope]; the protected benchmark did/did not retain an interface residual.
```

# P-C

## Title

**Scientific Problem Solving as Obligation-Driven Control**

Subtitle:

**A Protected Test of Minimum Sufficient Escalation in AI-Assisted Inquiry**

## Pre-results abstract — 138 words

Scientific agents must decide not only what answer to produce but what intervention is warranted: direct solution, more evidence, a stronger evaluator, model expansion, representation change, method revision or abstention. We formulate obligation-driven scientific control over plural state and compare it prospectively with simple, frozen-V1 and strongest adaptive parent-composed solvers. The central diagnostic is minimum sufficient escalation, defined over a prospectively registered partial order of interventions rather than a universal reasoning ladder. Protected evaluation spans V1 parity, simple-task non-regression, hidden-world discovery, multi-fault diagnosis, formal synthesis and governed scientific tasks. Primary outcomes include justified terminals, critical false completion, CANNOT_CHECK calibration, selective reopening, over- and under-escalation, component necessity and resource cost. Current autonomous-science systems are treated as strong adaptive parents. The study explicitly permits simple controls or parent federation to win; protected results determine whether any integrated control residual survives.

## Final abstract result slot

```text
V2_CONTROL_RESIDUAL:
  The candidate improved [justified outcome] over [strongest comparator] without violating frozen parity/false-completion thresholds and changed minimum-sufficient intervention selection by [effect].

CONTEXTUAL_REGIME_RESIDUAL:
  No always-on controller dominated; a frozen contextual selector improved [registered quality/resource outcome] by routing between simple and integrated regimes.

USE_DONOR_COMPOSED_SOLVER / F2_REDUNDANT_DRAG:
  The strongest parent-composed solver matched or exceeded the integrated controller at lower cost, providing no always-on F2 residual.

F2_HARMFUL_OR_OVERESCALATING:
  Integrated control increased [critical error/over-escalation], failing the registered non-regression gate.
```

# P-D

## Title

**When Agreement Is Not Independent and Evaluation Changes the System**

Subtitle:

**Dependence-Aware Evidence and Dynamic Evaluation in AI-Assisted Science**

## Pre-results abstract — 139 words

AI-assisted science can overstate evidence when apparently distinct agents, sources or validators share hidden causes, and an evaluator valid before optimization can become invalid after the system changes its environment. We test dependence-aware evidence control and dynamic evaluation as separate parent problems and ask whether a common validity interface adds protected decision value beyond their strongest composition. The benchmark includes copied and genuinely independent evidence, shared models/data/instruments, unknown and mis-specified dependence, partial evaluators, stable-environment controls and performative-response cases. Primary outcomes are false corroboration, calibration, over-conservative rejection, evaluator invalidation, selective reopening, CANNOT_CHECK and resource cost. Recent work on shared-information multi-agent limits, consensus misalignment and finite-evaluator reward hacking is treated as direct parent pressure. A unified-assurance claim is supported only if the joint interface changes scientific decisions beyond applying mature dependence and dynamic-evaluation methods separately; otherwise the paper splits or contracts.

## Final abstract result slot

```text
UNIFIED_ASSURANCE_RESIDUAL:
  The joint interface improved [protected decision/calibration] beyond the strongest separate parent pipelines while retaining genuinely independent evidence and stable-evaluator negative controls.

DEPENDENCE_ONLY_RESULT:
  Dependence-aware control improved [outcome], whereas the dynamic-evaluation component added no protected decision value; the unified claim was rejected.

PERFORMATIVE_ONLY_RESULT:
  Response-aware evaluation improved [outcome], whereas dependence integration was parent-sufficient; the unified claim was rejected.

TWO_PARENT_METHODS_SUFFICIENT:
  Separate mature parent methods reproduced the protected decisions, leaving no unified-assurance residual.
```

<=150 words total.
