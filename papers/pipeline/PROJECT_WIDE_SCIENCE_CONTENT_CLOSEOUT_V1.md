## 1. Governing rule

A paper can be **scientifically content-complete before results** if its:

- research question;
- parent ownership;
- formal object;
- hypotheses and falsifiers;
- methods;
- estimands;
- analysis plan;
- figure roles;
- negative-result interpretation;
- discussion boundaries;
- reproducibility/AI-use disclosures;
- venue route

are complete.

It cannot be called result-complete or submission-ready when a headline claim still depends on protected computation, independent adjudication, prospective follow-up or external field review.

Therefore this closeout maximizes scientific writing **without inventing Results**.

# 5. Flagship science update

The flagship V10 should replace a predominantly “scientific-state transition control” framing with a **transition ecology**:

```text
knowledge/source transition
    -> relation/transfer transition
    -> concept/representation transition
    -> method/formalism transition
    -> action/experiment transition
    -> evidence/evaluator transition
    -> agenda/meta-policy transition
    -> scientific commitment/authority transition
```

The common field hypothesis is not that these transitions share one implementation. It is that **cross-transition validity constraints and responsibility for change** form a testable higher-order object beyond independent local methods.

The programme must explicitly allow F0/F1/F3 to win.

# 6. Recursive development content

Population-level scientific-development learning belongs in the flagship as a **research frontier**, not an established foundation law.

Use the hierarchy:

```text
episodes
 -> discovered development operators
 -> operator families with preconditions/contraindications
 -> meta-policies selecting/sequencing operators
 -> higher-order principles
 -> recursive stability candidate, if no held-out residual remains
```

Every level is conditional on:

- success + failure trajectories;
- field/epoch holdout;
- strongest science-of-science parent;
- prospective generated/naturalistic decisions;
- resource and publication-bias accounting.

SD10's executed corpus/bias infrastructure is programme evidence only; it does not establish a meta-principle.
