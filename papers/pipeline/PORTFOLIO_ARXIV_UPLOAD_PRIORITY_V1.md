# Global rule

arXiv is the first **public scientific version**, not an advertising teaser. Every released manuscript must satisfy the same evidence/atomic/citation/integrity standard as its later journal version.

Journal submission can improve exposition and incorporate legitimate new evidence/corrections with explicit versioning, but cannot erase negative preprint evidence or strengthen a failed claim.
