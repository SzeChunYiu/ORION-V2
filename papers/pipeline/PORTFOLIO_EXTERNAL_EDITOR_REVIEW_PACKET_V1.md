# Portfolio External Editor Review Packet V1

**Programme:** ORION-V2 / Machine Epistemics  
**Purpose:** obtain independent human editorial judgments without asking external reviewers to reconstruct the full repository.

Same-model critique, a different prompt to the same AI, or an internal ORION contributor does not satisfy the independence gate.

## 1. Global reviewer instructions

For each paper, judge the **current contracted claim**, not the most ambitious historical ORION claim.

Required decisions:

```text
CORRECTNESS = CORRECT / MINOR_REPAIR / MATERIAL_DEFECT / CANNOT_CHECK
PARENT_ABSORPTION = DISTINCT_RESIDUAL / OBVIOUS_PARENT_COMPOSITION / ONE_PARENT_OWNS / CANNOT_CHECK
TOP_TIER_SCALE = CLEAR / BORDERLINE / TOO_THIN / NOT_STANDALONE
REAL_RESULTS_NEEDED = YES / NO / CURRENTLY_MISSING
PRIMARY_MANDATORY_CHANGE = free text
STRONGEST_PARENT_MISSED = free text
```

A reviewer should be encouraged to recommend contraction, merger or a lower-scope venue without being treated as adversarial failure.

# 2. FLAGSHIP review packet

Send:

- `FLAGSHIP_MACHINE_EPISTEMICS_MANUSCRIPT_V10_PROJECT_WIDE.md`
- `FLAGSHIP_ATOMIC_CLAIM_GATE_V1.json`
- `PROJECT_WIDE_SCIENCE_CONTENT_CLOSEOUT_V1.md`
- `TOP_TIER_VENUE_AND_AI_POLICY_CONTRACT_V1.md`

### Exact question

> Is Machine Epistemics, as a **falsifiable research programme about cross-mode scientific transitions** with F0/F1/F2/F3 competitors, a sufficiently coherent and useful emerging-topic Perspective to merit top-tier publication without declaring a new field prematurely?

### Mandatory hostile questions

1. Is “transition ecology” merely a relabeling of existing epistemic-control/provenance/assurance work?
2. Are F0/F1/F3 genuinely competitive or only rhetorical controls?
3. Does the Perspective treat enough contrary/limiting parent work?
4. Is recursive scientific-development learning too speculative for the main paper?
5. Is the proposed external witness boundary substantive or generic responsible-AI language?
6. Which section should be removed if the Perspective feels too broad?

### Editorial terminal

- `NMI_PERSPECTIVE_SCALE_CLEAR`
- `NMI_BORDERLINE_PRESUBMISSION_ENQUIRY`
- `BETTER_AS_REVIEW_OR_FIELD_PERSPECTIVE_ELSEWHERE`

## 8. Routing rule

External feedback can **contract** claims or close a paper. It cannot authorize a new theorem/result that was not prospectively registered.

```text
ONE_PARENT_OWNS or OBVIOUS_PARENT_COMPOSITION
    -> merge/drop/resource route

TOP_TIER_SCALE = CLEAR
    -> proceed only after result/author/policy gates

TOP_TIER_SCALE = BORDERLINE
    -> presubmission enquiry or stronger realistic fallback; no claim inflation

TOP_TIER_SCALE = TOO_THIN
    -> fallback/merge
```

## 9. Independence

Prefer reviewers/editors who:

- are not manuscript authors;
- did not build the benchmark/result;
- have relevant parent-field expertise;
- can criticize the programme without a stake in ORION terminology.

Field-demarcation review for the flagship should include multiple parent disciplines rather than one AI-systems reviewer.
