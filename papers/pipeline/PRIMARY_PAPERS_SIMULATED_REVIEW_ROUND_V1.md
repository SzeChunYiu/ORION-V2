# P-C — scientific control

## Validity reviewer

### PC-R1 — minimum-sufficient intervention uses hindsight oracle

**Concern:** `MinSuff(E)` is defined using the set of sufficient actions; a real agent does not know this set.

**Resolution:** the manuscript explicitly treats `MinSuff(E)` as an evaluator/known-answer object, not an online oracle supplied to the agent.

**Status:** `RESOLVED_BY_SEPARATING_EVALUATION_FROM_POLICY`.

### PC-R2 — blocker ontology could be circular

**Concern:** A benchmark whose authors define both blocker and preferred intervention could favor the controller vocabulary.

**Resolution:** blocker classes are evaluation labels, not universal ontology; comparator actions receive the same solver-visible information; parity/simple controls and hidden gold/independent semantic custody are mandatory.

**Status:** `RESOLVED_IN_DESIGN`; independent custody result remains open.

## Contribution reviewer

### PC-R3 — modern AI-scientist systems are already adaptive

**Resolution:** public master does not contrast with rigid pipelines. Residual concerns justified terminals, abstention, minimum intervention and late representation/formalism escalation beyond strong adaptive agents/parent controls.

**Status:** `RESOLVED_BY_PARENT_CONTRACTION`; direct citations required.

### PC-R4 — full integrated control may simply add drag

**Resolution:** always-SIMPLE, always-F0, always-F2 and contextual selector are explicit arms; over-control/drag is a main negative terminal.

**Status:** `RESOLVED_BY_EXPERIMENT_DESIGN`.
