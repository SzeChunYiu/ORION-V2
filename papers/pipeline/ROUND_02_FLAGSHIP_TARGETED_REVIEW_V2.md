## Reviewer arguments

### R1 — validity/methods/inference

The four-problem architecture is sufficiently coherent for a Perspective, provided it is presented as a research programme rather than an established unified theory. The manuscript correctly permits field falsification. The main scientific uncertainty is not internal logic but cross-domain recurrence: published examples motivate the object but do not yet prove one stable composition-level law across domains.

**Remaining blocker:** do not upgrade field recurrence from `BOUNDED_INFERENCE` to established result.

### R2 — contribution/prior work/target significance

The revised object is potentially significant because autonomous/agentic science makes scientific-process control timely. The anti-columbusing move is essential and unusually strong. However, direct epistemology parents must now be incorporated. A field-defining NMI Perspective could be appropriate if the final paper presents Machine Epistemics as a falsifiable organizing proposal rather than ownership of component theories.

**Remaining blocker:** parent genealogy and name demarcation need one more serious literature pass.

### R3 — reproducibility/readership/boundaries

V2 is far more reader-facing. Internal ORION architecture is gone. Remaining surface defects are straightforward. The bibliography is presently a verified core rather than a balanced Perspective bibliography; cybernetics, active experimentation, causal transportability, metrology/measurement invariance, systematic-review stopping, evidence synthesis and computational/machine epistemology need direct sources.

**Remaining blocker:** citation completeness/entailment and conceptual figures.

### R4 — field demarcation/history

The manuscript learned from the Machine Behaviour criticism by making parent subsumption a falsifier. The naming argument is not yet complete because computational epistemology and machine epistemology are closer intellectual parents than the current V2 text acknowledges. The field may still survive if its primitive object is held narrowly to **controlled scientific-process transitions**, but external reviewers must be able to repeat that distinction independently.

**Remaining blocker:** independent demarcation review remains non-self-closable.
