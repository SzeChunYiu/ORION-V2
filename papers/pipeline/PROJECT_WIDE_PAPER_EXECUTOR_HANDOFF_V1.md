## 2. Executor is allowed to

- run frozen experiments/computations;
- validate formal propositions mechanically;
- collect protected receipts;
- compute preregistered effect estimates/uncertainty;
- populate frozen result fields;
- regenerate figures/tables from receipts;
- select the Discussion branch corresponding to the registered primary terminal;
- contract text to the frozen journal word/display budget without changing scientific meaning;
- materialize citation/BibTeX metadata from the frozen related-work plan;
- compile Word/LaTeX/source-data packages;
- run page/style/citation/hash checks.

## 3. Executor is not allowed to

- invent a new theorem after outcomes;
- change a primary endpoint to obtain significance;
- add a new baseline only after seeing which one is easy to beat, unless treated as a new successor study;
- omit a parent-win/null/adverse/CANNOT_CHECK result;
- turn infrastructure failure into scientific failure/success;
- change false-analogy/native-fidelity/false-completion thresholds post hoc;
- redefine minimum sufficient escalation after seeing arm behavior;
- merge separate positive P-D lanes into a unified result if the joint discriminator fails;
- resurrect P-E/P-F/P-G without their evidence gate;
- declare Machine Epistemics a field;
- minimize AI-use disclosure;
- choose authors/COIs/reviewer suggestions;
- claim external independent review was obtained when it was not.
