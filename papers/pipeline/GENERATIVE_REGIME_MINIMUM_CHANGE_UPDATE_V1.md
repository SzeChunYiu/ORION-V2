## New computation burden

Only one new computation is recommended immediately:

```text
GR10 = exact synthetic generative-regime transformation benchmark
```

GR10 is designed to be small and exact-oracle. It determines whether the explicit regime interface has any residual beyond current F0/F2 and strongest parent transformation methods.

`GR20` is primarily curation + blinded evaluation and can proceed incrementally.

`GR30` is not authorized by default and opens only if GR10 shows a protected residual and GR20 does not attribute it to synthetic/surface effects.

Therefore no existing P-A/P-C protected campaign needs to be rerun solely because of this conceptual update.
