# P-D — dependence-aware evidence and dynamic evaluation

## Study archetype

Computational/statistical assurance + dynamic/performative evaluation.

## Independent unit

The registered evidence/evaluator/environment **case** is the primary unit. Multiple sources/agents within one case are explicitly dependent objects, not independent replicates.

## Data lifecycle

```text
evidence graph / source identities
-> known or registered dependence structure
-> evaluator/error-class contract
-> static or responsive environment state
-> arm decisions/assurance outputs
-> gold validity/reopening decision
-> analysis-ready case record
```

Unknown dependence is a distinct state rather than silently assumed independence.

## Primary estimands

Dependence lane:

- false corroboration / over-counting error;
- calibration or decision correctness under known dependence;
- sensitivity to misspecified dependence;
- preservation of genuinely independent support;
- unknown-dependence handling.

Dynamic lane:

- error under stable-environment negative control;
- error when system/environment responds to evaluation;
- evaluator-sensitivity/validity after response;
- correct reopen/maintain decision.

Joint lane:

- incremental protected decision value of the unified state/interface beyond applying the strongest dependence and performative-evaluation parents separately;
- resource overhead and overconservatism.

## Strongest alternative

The proposed unified object may be only a Cartesian coordination layer. If the separate parent pipelines reproduce all protected decisions, the unified-paper thesis contracts or splits.

## Result blocker

`P_D_ARXIV_RELEASE = BLOCKED` until protected dependence/dynamic/joint results close.
