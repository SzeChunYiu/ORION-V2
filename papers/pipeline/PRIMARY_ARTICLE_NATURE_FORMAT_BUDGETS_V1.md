# Primary Article Nature Format Budgets V1

**Papers:** P-A, P-B, P-C, P-D  
**Current official Nature Machine Intelligence / Nature Computational Science Article format checked:** 2026-08-29.  
**Common constraints:** main text up to 3,500 words; abstract up to 150 words; up to 6 display items; ~50 references guideline; Methods excluded from main-text word limit.

Pre-results science masters are intentionally longer and method-complete. The final Article is assembled **after Results** using the budgets below.

---

# P-A — NMI Article budget

## Main text target

```text
Introduction                      550–650
Results                           1,900–2,150
  Remote donor recovery             400–500
  Native fidelity / false analogy   400–500
  Target consequence / contraction  350–450
  Parent/expert comparison           350–400
  Resources / heterogeneity          300–350
Discussion                         650–750
TOTAL                            ~3,100–3,500
```

Methods holds:

- donor/target structural objects;
- benchmark construction;
- hidden parent/adjudication;
- comparator implementation;
- false-analogy/native-fidelity definitions;
- resource accounting;
- statistical analysis;
- leakage controls.

## Display items — maximum six

1. **Fig. 1** protected benchmark + donor-native-recovery pipeline.
2. **Fig. 2** remote donor recovery vs critical false analogy across arms.
3. **Fig. 3** native fidelity + target decision/contraction.
4. **Fig. 4** resource Pareto / strongest-parent comparison.
5. **Table/Fig. 5** case-level or domain/distance heterogeneity.
6. **Optional** negative-transfer/counter-probe examples or robustness; move to Extended Data if crowded.

Do not spend a main display on a generic ORION architecture diagram.

## Main text target

```text
Introduction                      550–650
Results                           1,850–2,100
  Relation/native known answers      350–450
  Formal propositions/countermodels  300–400
  Cross-parent reuse decisions       450–550
  Selective reopening                350–450

```

Online Methods holds:

- relation/context receipt schema;
- parent selector;

- cross-parent benchmark construction;
- hostile composition cases;
- reopening support-family cases;
- statistical/resource analysis.

## Display items

1. **Fig. 1** relation family/context schematic showing why one “similarity” axis is insufficient.
2. **Fig. 2** native-verdict preservation vs unsafe/missed reuse.
3. **Fig. 3** composition/obstruction known-answer cases.
4. **Fig. 4** selective reopening outcomes/support-family illustration.
5. **Table 1** formal proposition status: proved/parent-owned/contracted/CANNOT_CHECK.
6. **Optional** resource/parent-federation comparison.

If the cross-parent residual is absent, do not force six figures; contract the paper/content type.

# Main-text protection order under word pressure

Never cut first:

1. headline protected Results;
2. critical negative/parent-win results;
3. strongest current direct-parent comparison;
4. claim ceiling;
5. primary limitation affecting interpretation.

Move to Methods/Supplement first:

- full benchmark registry;
- exact implementation details;
- exhaustive secondary analyses;
- full formal proofs;
- additional countermodels;
- extended parent taxonomy;
- all-but-primary robustness tables.
