## 3. What the SD20 negative teaches the programme

The pilot supports four methodological lessons about the **research design**, not about universal science:

1. more conditioning is not automatically more informative;
2. intuitive fixed “breakthrough lessons” can be strongly anti-predictive;
3. a stable population regularity can coexist with no detected contextual operator residual;
4. recursive-development claims require outcome/trajectory information richer than metadata version transitions.

These lessons are about how to continue/contract the programme. They are not a publishable universal meta-science rule.

## 4. Revival rules

Only prospectively frozen successors may attempt:

- alternative transition alphabets;
- category-marginal rather than joint-context conditioning;
- wider multi-year source windows;
- lawful cross-source transition histories;
- richer source-bound process features;
- genuine success/failure/partial/abandoned trajectory outcomes;
- parent models that become identifiable with the richer data.

Each revival receives a new protocol/run identity if it changes the scientific representation being tested.
